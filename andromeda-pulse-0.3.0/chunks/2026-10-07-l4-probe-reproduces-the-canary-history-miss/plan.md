- **Verdict:** SELECTED (exit 0) with the arm named, or NONE (exit 1). NONE is recorded as measured: no product
  change ships, and the report says the miss reproduces on the replayed prompt and no listed candidate meets the bar.

## Test Commands
The chunk's own entries come first, then the standard gate set in test-plan §3 order: `capability-drift` before the
default-features workspace nextest, the `--features mcp-server` regen and the base-identity bindings close last, since
no procedure is added. The readings and the operator pass follow.

The first slot entry and the first reading were FIRED under this plan's first form, once, and are listed for the
record only: their result is `evidence/reading-reproduction.md`, and nothing fires them again. Every non-leg entry
reads green from Step 10 on. Before it, on the tree the stopped run left, the candidate dry-run and the section
self-read read red (the arms and the reader are Steps 7-8), and so does the probe unit entry once a pin is written
ahead of its code.

Three shell names carry what the capture supplies: `L4_REPLAY_MISS` and `L4_REPLAY_CONTROL`, the two invocation
directories, and `L4_REPLAY_OWN_LINES`, the pre-registered own lines. They are variables of these entries alone, set
by /implement for a leg. No binary reads them, so they are not environment variables of the product (architecture.md
§Occupied Resources holds no `L4_REPLAY` name: `grep -n` over the file, 0 lines).

Every entry that reads a capture is an operator leg, fired at /implement and never re-run by the wrap. The captures
are deleted when the chunk closes (inputs#I15), so each such leg's record in `evidence/` is all that remains of what
it read, and no pin, no non-leg entry and no evidence pointer needs a capture to exist.

Absences, each with its reason:
- No `pulse-app/ui/**` path is touched, so the webview gates are absent and there is no headful self-verify.
- No boot path is touched, so no boot-smoke entry is listed. The readings boot no app: the probe spawns `llama-cli`
  itself, binds no port and opens no corpus (research.md; scope.md §Boundaries).
- No local pre-push gate: `cargo xtask pre-push:linux` cannot run on this host; CI's `lint-test` job is the gate the
  push meets.
- No liveness probe keyed `round` precedes a reading: it drives no external process. Each reading's precondition is the
  operator's slot entry before it, no `llama-cli` resident on the GPU; the replay reading's is also the capture
  precondition entry, which composes both prompts and spawns nothing.
- No L4 latency grade: the probe emits no `metric.pipeline.l4.*` record, so that arm reads "not graded: no sample".
- No sha256 from the probe: the two prompts' hashes come from `sha256sum` over each `prompt.txt` in the capture
  precondition entry, read from stdin so no host path is printed.

Each reading is two-armed by design. Exit 0 and exit 1 are both a completed, recorded verdict; exit 2 measured nothing.
A reading's entry therefore asserts that the run completed and printed its verdict line, never an exit, and the verdict
word is carried into the report's Outcome. NOT REPRODUCED and NONE are never reported as passed.

The mutation checks of Steps 10 and 15 edit source and revert, so each is a ONE-SHOT run at implement, both readings
in `evidence/mutation-checks.md`; the triage and probe unit entries guard the same properties on every re-run. The
instruments this chunk builds meet their known-verdict controls before their graded use: the replay loader replays the
probe's own composition of a synthetic shape byte for byte, the section reader reads `S8` against `S16` (the section
self-read entry and its pin), each block edit is pinned equal to the same change made before rendering, and both
reading rules are fed synthetic counts for each outcome, all in the probe unit entry, which precedes every reading.

Evidence files are written by /implement from the entries' recorded outputs; each series' own files land under the
gitignored `target/l4-decision-probe/`. A capture's path is never written into evidence: an invocation is named by
its label, its directory's own name and the sha256 of its `prompt.txt`.

  captures never enter a repository (the founder's, inputs#I15; inputs#I14 §2). A shape derived from reading a
  capture is written synthetically, a title taking a form and never the text. A commit that would carry capture text

  the real prompt, and a synthetic shape that fails for another reason must not veto a real fix.

  once and read once. A clean reading is reported, never tuned away.
- Holding the remedy reading for the derived shape past the daylight — rejected (inputs#I16): it never blocks the
  remedy. A shape not built and green in time is left out, and no later slot is asked for it alone.

  would leave the scope guard's manifest clause.

  miss over the allowance — rejected by the operator (inputs#I11).
