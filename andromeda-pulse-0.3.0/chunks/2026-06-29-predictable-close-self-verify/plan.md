## Goal

Two coupled deliverables. **(A) P-063 — Predictable close + honest tray.** A live-dogfood premise correction grounds the
scope: close is NOT broken — `pulse-app/src/window.rs::on_window_event` (l.100-124) already does `api.prevent_close()` +
`handle_close_to_tray` → `window.hide()` (chunk #24's hide-to-tray, the arch §Tray-icon-policy default), wired globally at
`main.rs:1021`. Intent F3's "X doesn't quit / the dashboard cannot be closed" is the *symptom* of an **unsignposted**
hide-to-tray: the window vanishes with zero indication the app is still alive. The fix is the missing signpost, not a new
close mechanism — a one-time OS-native notification on the FIRST close ("andromeda-pulse is still running in the tray —
right-click to quit"), gated on the existing `Settings.notifications_enabled` (`crates/ui-bridge/src/contract.rs:119`),
emitted Rust-side via the already-initialized `tauri_plugin_notification` (`main.rs:1020`). The tray (icon + `Quit` →
`app.exit(0)`, `tray.rs:258-263`) stays the single honest "still running" surface; the static summary-line live-refresh is
explicitly out of F3 scope. Per arch §Tray-icon-policy + §OS-notification-policy + design-system §Surface desktop-native.

**(B) P-078 — Agent-headful self-verify harness (NEW).** A minimal, agent-runnable `cargo xtask self-verify` that boots the
REAL release binary (isolated data dir), asserts shell health from the structured log + window state, runs the existing
a11y/contrast harness, and **quits cleanly with zero orphan** — a deterministic pass/fail an agent can run unattended. This
is the chunk's larger deliverable and the strategic reason it is sequenced first: the close-fix (A) is the enabling
prerequisite for a clean-quitting headful gate, so every later Epoch-2/3 UI chunk can be autonomously boot→verify→quit
verified instead of shipped visually unseen (v0.2.0 passed 1676 tests yet shipped illegible). It COMPOSES existing pieces —
the agent-run boot/cleanup discipline (`scripts/agent-run.sh`), the `npm run test:a11y` suite (`pulse-app/ui/package.json`),
and the `agent-latest.jsonl` boot spans (obs-plan §3) — adding NO heavy deps. The FULL integration-UX e2e + headful
tauri-driver DOM/drag-delta is explicitly P-076 (Epoch 4), which already CARRIES the P-061 drag-delta residual.

**B — xtask self-verify (P-078)**

6. Orchestration (deterministic, machine-parseable, single exit code): (a) boot the real release binary with an isolated
   `ANDROMEDA_PULSE_DATA_DIR` tempdir via `tokio::process::Command` with `kill_on_drop(true)` (reuse the `scripts/agent-run.sh`
   boot pattern); (b) **assert shell health** by tailing `<data_dir>/logs/agent-latest.jsonl` for `app.boot` + child boot

   (SIGTERM / the tray-quit path) and assert no orphan via `tasklist` (Windows) / `ps` (Unix); (e) aggregate to exit 0 (all
   pass) / non-zero (any fail).
7. Headless tolerance: on a display-less environment where the GUI app cannot boot, detect and **skip-clean** (deterministic
