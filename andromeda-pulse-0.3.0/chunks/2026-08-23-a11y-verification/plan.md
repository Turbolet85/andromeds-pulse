## Goal

Verify the v0.3.0 interactive surfaces for focus / keyboard / contrast / SR + SC 2.3.3, and — equally —
make the a11y specs describe the product that actually ships. Research measured that this chunk is
**much smaller than its route entry implies**: the sweep is largely already covered, and the single
loudest claim it inherited is false.

Five artifacts (the working entry, a11y-plan §1 P1, §1 P4, §5, §7, and test-plan §1's
`traces-surface-a11y-semantics-absent` trigger) assert the Traces surface ships **neither** a region
label **nor** a `table` role. Both halves are wrong at HEAD. `TraceTable.tsx:115` renders a native
`<table>` with `<thead>`/`<tbody>`/`<th scope="col">`/`aria-sort` and no `display:` override, so the
implicit ARIA `table` role is intact; and `ConstellationCanvas.tsx:229` already wraps the canvas in a
named `<section>`, which *is* `role="region"`. The claim also mis-located the region — a11y-plan §7
assigns it to the canvas wrapper, a **sibling** component, while all five artifacts looked for it inside
`TraceTable.tsx`. Per a11y-plan §11 the shipped shape is in fact the *preferred* one: adding
`role="table"` to a native `<table>` would be the banned ARIA-duplicates-semantics anti-pattern.

So the work is: (1) close the one genuinely unbuilt item — trace-list **row-level** keyboard navigation,
which a11y-plan §5 deferred on the now-void premise that the `table` role was unshipped; (2) give the
canvas region a **stable** landmark name while preserving the aggregate summary as a description — the
operator-selected hybrid, which also fixes a smell neither side had: a landmark whose name mutates with
data destabilises the screen-reader rotor; (3) add the deferred Investigate result/error/progress axe

## Constraints & rejected approaches

- **Do NOT add `role="table"` to the native `<table>` or `role="region"` to the named `<section>`** — both
  would be the ARIA-duplicates-inherited-semantics anti-pattern a11y-plan §11 bans. The specs' absence
  claim is what is wrong, not the markup.
- **Full 2-D cell traversal — REJECTED** (operator decision, P4). On a 4-column read-only table with one
  action per row it adds focus stops that lead nowhere and carries the most regression surface; WCAG AA
  needs no cell-level traversal here. Row-level is the shipped shape; a11y-plan §5 is amended to match.
- **Renaming the region to the literal and dropping the summary — REJECTED** (operator decision, P4): it
  would remove information AT users already receive. The hybrid keeps both.
- **Announcing the summary through `StatusLiveRegion` instead of `aria-describedby` — REJECTED**: that
  channel is a transient `role="status"` announcement queue, so the summary would be unavailable
  on-demand; a description is persistent and reachable whenever the landmark is focused.
- **Do NOT build or delete the Halo State Pulse canvas.** It has zero production render sites (measured),
  and build-or-retire is explicitly the "Halo State Pulse canvas disposition" entry's decision.
- **Do NOT drive the live cross-window findings/report focus restoration** — CARRY-2 assigns it to the
  "Headful leg extension" entry. Static coverage (disclosure trigger, dialog role/name) only.
- **Do NOT loosen the CSP, add a Tauri core-API or `core:window:*` grant, or add a TauRPC procedure** to
  make tooling pass (security-plan §API Security; arch §Webview IPC capability policy).
- **Do NOT edit any `.andromeda/` spec master** — corrections ride wrap's amendment flow (below).
