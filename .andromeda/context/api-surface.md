## Planned surfaces (initial seed — replaced by tooling output on first reconcile)

### IPC methods (TauRPC procedures)

Per arch §Standard Contracts Tauri IPC introspection + §Occupied Resources Tauri IPC routes; webview-to-Rust direction; gated by `pulse:default` capability JSON.

**Top-level cross-cutting envelope (ui-bridge crate):**

- **`app_info`** (webview → Rust) — application identity envelope: name / version / rust_version / tauri_version / features / build_profile.
- **`health`** (webview → Rust) — liveness state of in-process subsystems (otlp_grpc_receiver / otlp_http_receiver / buffer / ingest_channel) with `status: ok | degraded` + `subsystems` map + `pid` + `uptime_ms`.
- **`ready`** (webview → Rust) — readiness state with `ready: bool` + `checks` map (duckdb_connection / ingest_mpsc_capacity_pct / broadcast_subscribers / plugins_loaded / mcp_server_enabled).
- **`get_settings`** (webview → Rust) — read user settings (theme / widget / retention / MCP toggle / snapshot preset / plugin manager).
- **`update_settings`** (webview → Rust) — write user settings with validation + persistence to `~/.andromeda-pulse/config.toml`.

**Per-router dotted namespaces (per crate):**

- **`traces.*`** (webview → Rust; viz crate) — `traces.query` returns paginated trace rows; additional `traces.{verb}` routes per arch §Occupied Resources viz routers.
- **`metrics.*`** (webview → Rust; viz crate) — `metrics.query` returns paginated metric points.
- **`logs.*`** (webview → Rust; viz crate) — `logs.query` returns paginated log records.
- **`snapshot.generate`** (webview → Rust; snapshot crate) — generates curated markdown snapshot with token budget enforcement.
- **`snapshot.list_recent`** (webview → Rust; snapshot crate) — lists recent snapshot files in `~/.andromeda-pulse/snapshots/`.
- **`snapshot.copy_to_clipboard`** (webview → Rust; snapshot crate) — copies snapshot markdown to clipboard with visible event emission.
- **`plugins.list`** (webview → Rust; plugins crate) — lists loaded plugins with name / capability list / status.
- **`plugins.reload`** (webview → Rust; plugins crate) — reloads plugins from `~/.andromeda-pulse/plugins/` directory.
- **`plugins.invoke`** (webview → Rust; plugins crate) — invokes plugin capability with input; capability-gated.
- **`mcp.status`** (webview → Rust; mcp-server crate, feature-gated) — MCP sidecar status.
- **`mcp.start`** (webview → Rust; mcp-server crate, feature-gated) — start MCP sidecar.
- **`mcp.stop`** (webview → Rust; mcp-server crate, feature-gated) — stop MCP sidecar.
- **`workspace.detect`** (webview → Rust; workspace-detector crate) — detect current host project context.
- **`workspace.list`** (webview → Rust; workspace-detector crate) — list detected workspaces.

All TauRPC procedures return `Result<T, AppError>` per arch §Conventions Error response schema (Tauri IPC); error variants `Validation` / `NotFound` / `Internal` / `Plugin` / `Storage` / `Ingest` are sanitized at the bridge.

### HTTP endpoints (OTLP receiver — `:4318`)

Per arch §Standard Contracts OTLP receiver spec-conformance; bound to `127.0.0.1` only per arch §Occupied Resources network ports + security plan §Threat Model Summary.

- **`POST /v1/traces`** — accepts OTLP trace payloads (protobuf or JSON per OpenTelemetry HTTP spec); returns 200 OK with empty body on success or `Status` proto on error per OTLP spec.
- **`POST /v1/metrics`** — accepts OTLP metric payloads.
- **`POST /v1/logs`** — accepts OTLP log payloads.

Body size limit: 8 MB via axum `DefaultBodyLimit::max(8 * 1024 * 1024)`. Host-header allowlist enforced per security plan §API Security DNS rebinding mitigation. CORS deny-by-default per security plan §API Security CORS.

### gRPC services (OTLP receiver — `:4317`)

Per arch §Standard Contracts OTLP receiver spec-conformance; bound to `127.0.0.1` only.

- **`opentelemetry.proto.collector.trace.v1.TraceService/Export`** — accepts OTLP trace export RPC.
- **`opentelemetry.proto.collector.metrics.v1.MetricsService/Export`** — accepts OTLP metric export RPC.
- **`opentelemetry.proto.collector.logs.v1.LogsService/Export`** — accepts OTLP log export RPC.

Decoding message size limit: 8 MB via tonic `.max_decoding_message_size(8 * 1024 * 1024)`. gRPC errors use standard `tonic::Status` codes per arch §Conventions Error response schema (OTLP receiver).

### MCP stdio surface (feature-gated `--features mcp-server`)

Per arch §Standard Contracts MCP server spec-conformance; only present when binary built with `--features mcp-server` AND `ANDROMEDA_PULSE_MCP_ENABLED=true` runtime flag.

- **`tools/list`** (stdin → stdout) — returns the 4 tool methods per JSON-RPC 2.0 framing.
- **`tools/call`** (stdin → stdout) — invokes a tool method:
  - **`query_traces`** (`time_range, service_filter, limit`) — returns array of trace objects.
  - **`query_metrics`** (`metric_name, time_range, aggregation`) — returns array of metric points.
  - **`query_logs`** (`filter, time_range, limit`) — returns array of log records.
  - **`generate_snapshot`** (`time_range, token_budget`) — returns curated markdown snapshot.
- **`initialize`** / **`notifications/*`** — MCP spec defaults.

JSON-RPC 2.0 errors use standard MCP-spec error codes per arch §Conventions Error response schema (MCP). Stdout is reserved for JSON-RPC framing per obs plan §3 Logging stack mcp-server stderr forced.

### Event topics (Tauri IPC `Channel` API — binary Arrow IPC payloads)

Per arch §Standard Contracts Real-time push contract + §Occupied Resources Tauri IPC events.

- **`pulse://stream/spans`** (Rust → webview) — live span stream from buffer broadcast fan-out; binary Arrow IPC payload + `_trace_context` metadata column.
- **`pulse://stream/metrics`** (Rust → webview) — live metric stream; binary Arrow IPC payload.
- **`pulse://stream/logs`** (Rust → webview) — live log stream; binary Arrow IPC payload.
- **`pulse://stream/snapshot-progress`** (Rust → webview) — snapshot generation progress events; emitted at clipboard-write time per security plan §Logging snapshot/clipboard hygiene.
- **`pulse://stream/plugin-events`** (Rust → webview) — plugin lifecycle events (load / reload / invoke / unload).

### Schema files / public exports

Per arch §Established Decisions [Plugin Runtime] WIT interfaces + §Occupied Resources WIT directory location.

- **`crates/plugins/wit/*.wit`** — WIT interface definitions for 3 plugin categories (custom-dashboard / data-transform / snapshot-template); WASM Component Model contract for capability-scoped guests.
- **`pulse-app/capabilities/*.json`** — Tauri 2 capability JSON files: `pulse:default` (enumerates exact TauRPC procedures permitted to webview), `pulse:tray`, `pulse:notification`, `pulse:updater`, `pulse:plugin-fs`.
- **`pulse-app/tauri.conf.json`** — Tauri configuration including bundle id `com.andromeda.pulse`, CSP literal (`script-src 'self'` + WebGPU `worker-src blob:`), Tauri updater Minisign Ed25519 public key (private key in Azure Key Vault per security plan §Secret Management).

Each library crate's contract module is the only `pub` surface per arch §Conventions Module visibility discipline; cross-crate utilities use `pub(crate)`.
