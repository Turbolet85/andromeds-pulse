## Anti-patterns к avoid

- **NEVER include visual regression with human review** (Percy / Chromatic / Applitools) — agent-driven discipline prohibits human screenshot approval (per test-plan §11 E2E ban + §11 Universal ban). WCAG 2.1 contrast assertions consume programmatic ratio output (colorjs.io / axe-core), not visual diff.
- **NEVER use `sleep(N)` for synchronization** in perf-test load drivers (per test-plan §11 E2E ban) — wait for explicit signal via `health` TauRPC polling (`subsystems.buffer.rows_ingested >= 100000`), or until perf measurement window closes deterministically via `tokio::time::pause()` + `advance()`.
- **NEVER lower coverage / perf-budget thresholds to pass build** (per test-plan §11 CI + Quality bans) — raise code quality instead. If the 10k spans/sec gate fails, root-cause the ingest path; do not relax the budget.
- **NEVER auto-retry flaky a11y or perf tests** (per test-plan §10 Zero-flakiness + §11 Quality ban) — single flake = quarantine + root-cause; retry policies mask real bugs in WebGPU adapter selection / DuckDB appender contention.
- **NEVER use real-time `chrono::Utc::now()` / `std::time::Instant::now()` for perf-budget windows without injection** (per test-plan §11 Universal ban) — `tokio::time::pause()` + `advance()` is the deterministic clock primitive.
