## Anti-patterns to avoid

- NEVER promote SR manual pass to sole gate — it is supplemental only; automated axe-core / Lighthouse / pa11y must remain primary CI gates (per a11y-plan §11 Universal + §3 Screen reader test pattern).
- NEVER use vendor-locked or commercial-only SR tooling as the only path — stick to open-source NVDA + Orca and OS-bundled VoiceOver per a11y-plan §3 Browsers + SRs per platform (free / open-source explicit).
- NEVER omit structured JSON output from manual pass — every manual pass must emit machine-parseable records, per agent-driven invariant (a11y-plan §1 invariant: "every WCAG criterion described in this plan MUST have at least one agent-runnable verification path").
- NEVER skip a Critical Path P1–P7 from SR fixture coverage — zero-coverage on a must-be-accessible path is a SLO violation per a11y-plan §10 ("Zero WCAG AA violations on must-be-accessible paths").
