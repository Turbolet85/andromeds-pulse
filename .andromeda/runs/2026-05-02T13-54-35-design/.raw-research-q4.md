## Expression Level

### Base level

**Recommended base:** 0.3
**Reasoning:** andromeda-pulse is a developer tool (not general consumer SaaS) where power users value restraint over visual polish; the Q1 "Ambient constellation — luminous, patient, emergence-driven" personality explicitly anchors contemplative, observational motion that conveys state without theatrical haste; the Q2 reference pair (Linear + Raycast) both operate at 0.3 expression — Linear uses motion-as-state-change transitions (minimal, purposeful), and Raycast demonstrates invisible-until-summoned UI with zero decorative motion. The Minimal security tier imposes no auth-distraction constraints, but the product's core use case (staring at telemetry for hours) demands motion that guides without fatiguing. 2026 trends confirm that meaningful motion design has shifted from "energy for its own sake" to "clarity through purpose" — subtle transitions confirm actions and filter state changes rather than animated entrance sequences. This level avoids bloat (no framer-motion complexity for a local dev tool) while honoring the "glance-readable from 2 meters" requirement and the brief's explicit rejection of Datadog / Neon gradient excess.

## Recommended

**Final expression map:**
- Base: 0.3
- desktop-webview: 0.35
- desktop-native: 0.2

**Reasoning:** At 0.3 base, andromeda-pulse honors its developer-tool positioning and the explicit brand personality (contemplative, patient, pattern-seeking) while leveraging 2026 industry consensus that purposeful motion clarifies interaction and state change without demanding attention. The per-surface split reflects the architectural reality: the webview (React/CSS/JS chrome) can support slightly richer microinteractions because it occupies dedicated screen space (always-visible widget or expanded dashboard), while the native tray surface must remain minimal to respect platform conventions and avoid visual clutter in the system taskbar. This expression level deliberately stays in Linear/Raycast territory (0.3–0.35), rejecting the high-expression showcase aesthetic (0.7+) and aligning with developer preferences for restrained, signal-focused design. The brief's canvas motion (WebGPU shader-driven Service Constellation halos, Latency River flows, throughput counter easing) is a separate dimension required by the architecture and not governed by the chrome expression number — that motion-as-data layer operates independently of these CSS/React transition guidelines.
