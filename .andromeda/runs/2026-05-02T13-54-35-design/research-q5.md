## Signature Candidates

### Candidate 1: "Halo State Pulse — Service Icon Aura Encoding Throughput & Error Rate"

**What it is:** A circular animated halo glow that emanates from each service constellation dot in the dashboard canvas, pulsing at a rate proportional to service throughput and shifting color (Earth Blue → Alert Burgundy) based on error rate. The halo breathes inward and outward at 0.6–1.2s cycles (modulating rhythm with live metrics), with a 12-16px blur radius at peak, 4px at minimum. On the tray icon, this condenses to a single unified halo around the aggregated service-count badge. The animation respects `prefers-reduced-motion`, degenerating to a static halo or icon outline. This is canvas-motion (WebGPU shader-driven, outside the 0.3 chrome budget).

**Implementation:** WebGPU compute shader driven (separate from React render tree). The halo is a radial gradient rendered to a secondary canvas layer every 16ms, sampled from live telemetry state (throughput counter, error rate boolean). Pulsing frequency is `heartbeat_hz = clamp(throughput_hz / 1000, 0.8, 2.4)` — services at 1K spans/sec pulse at ~0.8 Hz, 10K spans/sec pulse at ~2.4 Hz. Color interpolation in LCH color space (Linear reference) between Earth Blue #4A90E2 and Alert Burgundy #8B2E3B. shadcn/ui canvas container + Tailwind positioning for tray variant. Respects system `prefers-reduced-motion` via CSS media query toggle.

**Core-action tie:** Passive telemetry watching. The halo is the always-visible signal layer — developers glance at constellation and immediately recognize throughput patterns (pulsing rhythm) and error states (color shift) without reading numbers. Appears on both widget primary surface and full dashboard.

**Brand fit:** Synthesizes Q1 "luminous, patient, emergence-driven" (halos emerge from darkness like stars, pulsing rhythm is patient observation, not frantic); Q3 NASA Artemis mood (Alert Burgundy + Earth Blue directly from palette, halo mimics amber safelight aura preservation of dark adaptation); Q4 expression (canvas motion lives outside chrome 0.3 constraint, shader-driven pulsing is performant at 0.6–2.4 Hz, no VDOM cost). Directly instantiates brief's "Service constellation" signature element.

### Candidate 2: "Investigation Capture Collapse Animation — Snapshot Object Coalesces Into Focus Button"

**What it is:** When the user clicks "Investigate" on a trace snapshot, all visible telemetry cards (service constellation, latency river, log excerpt) animate into a single compact "snapshot object" — a 120px square card floating near the center of the screen for 400ms before auto-copying the curated markdown + AI-ready prompt to clipboard and firing an OS notification. The collapse uses scale + opacity easing (cubic-bezier 0.25, 0.46, 0.45, 0.94) over 350ms, gathering disparate signals into one focal point. After copy, the card briefly flashes white-blue highlight (#E8EEF7) and fades. This is a React component animation within the 0.35 webview expression budget.

**Implementation:** Framer Motion (or Tailwind @apply + CSS keyframes for CSP compliance — prefer vanilla CSS since Tauri CSP is strict). Snapshot card is a shadcn/ui Dialog primitive with custom animation: `transform: scale(0) translate(-50%, -50%); opacity: 0` → `transform: scale(1) translate(-50%, -50%); opacity: 1` over 350ms on mount. The snapshot object displays a minimal icon (magnifying glass or code bracket) + "Snapshot captured" label. On completion, it unmounts with reverse animation. All motion respects `prefers-reduced-motion` (degrades to instant show/hide). Token-efficient markdown generation happens in-flight (Rust backend, streamed to JS via TauRPC).

**Core-action tie:** Investigate snapshot capture. This is the moment of differentiation — the single-click action that captures a token-efficient curated markdown snapshot and copies an AI-ready prompt to clipboard. The animation makes the action feel **tangible** — signals are gathered into a concrete object, confirming the user's intent has been captured and is ready for handoff to AI assistant.

**Brand fit:** Synthesizes Q1 "emergence-driven" (signals coalesce from distributed state into a single emergent object); Q3 NASA mood (Status White-Blue #E8EEF7 flash on completion echoes the mission-control "status confirmed" highlight pattern); Q4 expression (350ms transition at 0.35 webview budget is well within spec, cubic-bezier easing is patient and purposeful, no spring physics). References the brief's "Investigation portal" and CleanShot X "Quick Access Overlay" pattern (capture flow gathers action into a moment).

### Candidate 3: "Latency River Color Modulation — Hue Shifts with P95 Latency Magnitude"

**What it is:** The "Latency River" (the GPU-rendered horizontal stream of recent traces) shifts its hue in real-time based on P95 latency values. When P95 < 50ms (healthy), the river maintains a cool Earth Blue (#4A90E2) hue. As P95 climbs (50–200ms), the hue gradually transitions toward Alert Burgundy (#8B2E3B) via LCH perceptual ramp. Above 200ms, it holds full Alert Burgundy. The transition is a smooth easing curve (0.3s response time) that doesn't flicker — it's a slow drift rather than a snap. This river renders as a WebGPU canvas element, separate from the chrome 0.3 budget.

**Implementation:** WebGPU shader that samples the rolling P95 histogram from the telemetry stream (updated every 1s from Rust backend). Hue interpolation happens in fragment shader space (LCH → RGB conversion). The river is a horizontal band (height ~60px in webview, ~20px in tray widget) with flowing particle or line animation representing individual traces. Color easing uses a simple exponential smoothing filter (`new_hue = lerp(old_hue, target_hue, 0.1)`) to avoid snapping. All motion respects `prefers-reduced-motion` (river becomes static, color shift becomes instant). React container manages the canvas dimensions; Rust backend streams P95 updates via TauRPC every second.

**Core-action tie:** Passive telemetry watching. The river is the second always-visible layer (after constellation halo). Developers recognize latency trends at a glance — gradual color drift signals degradation, steady blue signals health. No click required; it's ambient observation.

**Brand fit:** Synthesizes Q1 "ambient constellation — luminous, patient, emergence-driven" (color drift is patient, gradual, non-alarming emergence of latency signals); Q3 NASA Artemis mood (LCH color space interpolation between Earth Blue + Alert Burgundy directly echoes NASA mission-control palette logic); Q4 expression (WebGPU canvas motion is outside chrome 0.3 constraint, 0.3s response time is within "patient observation" philosophy). Directly instantiates brief's "Latency river" signature element and honors the "motion-as-data" principle (hue change reflects telemetry magnitude, not decoration).

## Recommended

**Recommended signature:** Candidate 1 — "Halo State Pulse — Service Icon Aura Encoding Throughput & Error Rate"

**Reasoning:** This signature best synthesizes ALL prior brand picks. It is the single most recognizable, specific, and implementable element that appears at the moment that defines the product — **passive telemetry watching**. The pulsing halo is visible at both the tray icon scale (aggregate health pulse) and the full constellation canvas (individual service halos), making it scale-invariant like the astronomy observatory metaphor. It directly embodies Q1 personality (luminous emergence from darkness, patient rhythmic pulsing, pattern recognition) and Q3 mood (Earth Blue + Alert Burgundy from NASA Artemis palette, halo mimics amber safelight dark-adaptation preservation). Q4 expression is honored: canvas motion lives outside the 0.3 chrome budget, shader-driven pulsing at 0.6–2.4 Hz is performant and GPU-native. The signature is implementable with Phase 1 tooling (WebGPU + React canvas container + Tailwind). Most critically, it is **traceable to product's core user action** — developers stare at the dashboard for hours, and the pulsing halo is the persistent signal layer that conveys state through motion-as-data (rhythm = throughput, color = error rate). Unlike generic "memorable design," this is a concrete, specific visual element with measurable parameters tied to live telemetry. The halo is the product's signature because it makes the observable cosmos visible to the developer's eye.
