# design extract

## Relevance
Partial — this chunk renders no UI (cue→cadence→digest→generation seam in `crates/triage` + the `pulse-app` subscriber boundary); design applies only where the damper changes the *inputs* to the signature element's encoding axes (active-incident severity, activity state, connection/liveness).

## Constraints
- The constellation-dot / Halo hue is mandated to be driven by **cumulative incident severity** (max active-incident priority tier), not by error rate or generation counts (per design-system §Brand Identity → Signature element; §Motion → High-impact moments (1)). Outcome 2 of this chunk (incident population converges instead of churning at ~5 permanently active) directly changes that input, so the damper must not suppress a genuine tier escalation from reaching it. Whether the code already routes active-incident severity to that driver at this seam is research's question.
- **Connection/liveness is an orthogonal grayout-desaturation axis, independent of the severity-hue axis** (P-004 health-vs-severity orthogonality; per §Brand Identity → Signature element and §Motion → High-impact moments (1)). The chunk's "quiet because damped vs quiet because dead" distinction (Outcome 3) must resolve on the liveness axis, never by muting the severity axis.
- Breathing cadence is mandated to be driven by an **activity-state tier** (period 4–5 s quiet → ~2 s under active flow, ≈0.2–0.5 Hz), explicitly *not* raw throughput (per §Motion → High-impact moments (1)). If the damper introduces an "unchanged/idle" condition tier, design requires the activity tier stay derived from telemetry flow, not from L4 generation frequency.
- The signature element's canvas/blur layer is **SPECIFIED but measured unbuilt on desktop-webview** (2026-08-21), and build-or-retire is owned by the separate "Halo State Pulse canvas disposition" route entry — which the chunk's Boundaries explicitly exclude (per §Brand Identity → Signature element). Design therefore adds no rendering work to this chunk.
- Any state this chunk makes operator-visible must not be reduced to a binary alive/dead glyph — uniform monochrome status icons are a rejected default precisely because two independent dimensions (liveness rhythm + severity hue) must both be readable (per §Anti-Patterns → Rejected Defaults).
- If any readout does land (not planned by the scope), it is token-only — no hardcoded hex or px literals, values traceable to the Color World / spacing scale / font stack (per §Self-Validation Protocol → Token Test; §Anti-Patterns → Universal Bans).

## Patterns to follow
- **Honest-error-before-empty branch** (§Surface: desktop-webview → Component Patterns → Loading / Empty States): the shipped `EmptyState` requires the error variant be checked BEFORE the empty branch so a failure never masquerades as "no data". This is the design-side precedent for Outcome 3 — "quiet because damped" must not present identically to "quiet because dead"; the same discipline (distinct branch, static honest message, accent as border/icon only) applies if the damper ever surfaces.
- **Severity → hue encoding contract** (§Brand Identity → Signature element): severity reaches the surface as an LCH position on Earth Blue #4A90E2 ↔ Alert Burgundy #C7556A; a damper that changes incident lifetime changes what that position reads. Preserve the driver, damp the generation.
- **Activity-state tiering, not raw-rate mapping** (§Motion → High-impact moments (1)): the 2026-05-29 model replaced a clamped raw-throughput mapping with a discrete activity tier — the same shape a growing-refractory or unchanged-condition tier should take if one is introduced.
- **Data/Code type roles** (§Typography): if any count (suppressed generations, active incidents, refractory seconds) is rendered anywhere, it is JetBrains Mono 12px with tabular numerals, not sans.

## Anti-patterns to avoid
- **NEVER collapse liveness into the severity axis** — a damped-quiet service must not read as a healthy one, nor a dead one as merely quiet (per §Brand Identity → Signature element P-004; §Anti-Patterns → Rejected Defaults "uniform monochrome status icons").
- **NEVER convey a suppressed / reused-generation state by color alone** — pair with a text label or icon; Accent #C7556A is a non-text token (≈3.8:1 on Base) and is never body-size state text (per §Color Palette → Accent usage (non-text token)).
- **NEVER introduce chrome motion for damper feedback beyond the 150–200 ms ease-out budget**, and no entrance animations (per §Motion → Hard limits; expression 0.35 webview / 0.2 native).

## Contract bindings
- **design ↔ obs:** the handoff index (design-system-amendments §Downstream Readiness → "For obs specialist") requires Halo pulse frequency and Halo color state be exposed as measurement hooks logged as-is without re-clamping. If this chunk alters the activity-state or incident-severity inputs, obs owns the exact allowlist leaf for the damper outcome (per scope Outcome 3); design's requirement is only that those logged values remain traceable to the two named drivers.
- **design ↔ a11y (conditional, only if UI lands):** state color pairs with label/icon → SC 1.4.1; any token pair used for text meets SC 1.4.3 4.5:1 (§Color Palette → Text Hierarchy targets); any animation honors `prefers-reduced-motion` → SC 2.3.3 (§Motion → Accessibility).
- **design ↔ capabilities:** P-004 (health-vs-severity orthogonality), P-025 (Halo hue encoding), P-026 (breathing encoding, opacity+blur never scale) are the capability anchors for the three drivers above.

## Acceptance criteria contributions
- The damper must not prevent a genuine incident severity-tier escalation from reaching the cumulative-incident-severity input that drives the signature hue; a converged (damped) population still reflects the max active-incident priority tier (per design-system §Motion High-impact moments (1) / §Brand Identity Signature element). Whether the code already routes that input at this seam is research's question.
- A damped-quiet system must remain distinguishable from a disconnected/dead one, with liveness resolved on its own orthogonal grayout axis and never folded into the severity hue (per design-system §Brand Identity Signature element, P-004 orthogonality).
- Any operator-visible readout of a suppressed/reused-generation outcome conveys state with a label or icon rather than color alone, and uses only design tokens (no hardcoded hex or px values) (per design-system §Color Palette Accent usage (non-text token) + §Self-Validation Protocol Token Test).
- This chunk introduces no new chrome animation; if any is added, it stays within 150–200 ms ease-out with no entrance/stagger and honors `prefers-reduced-motion` (per design-system §Motion Hard limits + §Motion Accessibility).
