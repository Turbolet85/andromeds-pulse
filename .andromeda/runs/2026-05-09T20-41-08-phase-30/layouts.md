- Do NOT use the OS-default Tauri window chrome (system titlebar + system window controls) — the full dashboard MUST share the custom frameless titlebar design with the compact widget for cross-surface visual cohesion (per layout-templates.md §Decisions Log "Cross-surface IA decisions" — "Compact widget and full dashboard share the same custom frameless titlebar design").
- Do NOT add tabs outside the 5 reserved labels (Traces / Metrics / Logs / Snapshots / Settings) — additional functionality is exposed via modals (Investigate, Settings forms) or command palette entries, not via top-level tabs (per layout-templates.md §Component — Primary navigation §"Tab / sidebar structure").
- Do NOT bind Cmd+K / Ctrl+K to anything other than the command palette, and do NOT bind Cmd+Shift+P / Ctrl+Shift+P to anything other than compact↔full toggling — the three keyboard shortcuts (Cmd+K, Cmd+Shift+P, Esc) form the contract for dashboard navigation entry/exit (per layout-templates.md §IA notes "Keyboard shortcuts").
