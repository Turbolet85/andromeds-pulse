## Anti-patterns to avoid

- NEVER widen `pulse:tray` capability JSON to include input-event handlers (notification action callbacks, tray menu items wired to invoke arbitrary IPC) — converts the outbound-only tray surface into a phishing / IPC-abuse vector. The capability JSON MUST list only the outbound emit subset (per security plan §Security Anti-Patterns § API).
- NEVER toggle MCP from the tray menu by directly invoking `mcp.start` / `mcp.stop` without the compile-time-feature-flag check — single-gate spawning is a regression of the architecture-declared double-gate (per security plan §Security Anti-Patterns § Code Patterns + §API Security row "MCP feature double-gate").
- NEVER add a `tray.*` TauRPC namespace AND ship chunk #36 without (a) the `pulse-app/capabilities/` JSON entry AND (b) the `/andromeda-scope-arch` update to arch §Occupied Resources Tauri IPC routes — silent capability-drift D3 will compound and the bridge will reject calls at runtime (per CLAUDE.md security.md Session Additions 2026-05-09 first entry + 2026-05-10 entry).
