### axum DefaultBodyLimit + tonic max_decoding_message_size (built-in, must enable)

- **Version:** axum 0.8.x; tonic 0.14.x
- **Last release:** Current
- **Status:** actively maintained
- **Fits because:** Direct mitigation for the JFrog axum-core DoS root cause and the tonic 1 GB-unary-request issue. Both `:4317` and `:4318` accept user-content payloads.

### Host header validation (DNS rebinding mitigation, must add)

- **Version:** Built-in axum middleware pattern
- **Last release:** Pattern is current 2025-2026
- **Status:** actively maintained pattern
- **Fits because:** Threat assessment explicitly flagged in "Open consideration for downstream phases" — `fetch('http://localhost:4318/v1/traces', ...)` from a malicious website is the documented MCP-localhost exposure (Coder Agent API CVE 2025-09-19; CVE-2025-66414 against MCP TypeScript SDK in Dec 2025; Chrome 142 added Local Network Access in 2025).
- **Key detail:** "localhost is not a security boundary" is the explicit lesson from 2025-2026 incidents. Mitigation for the OTLP HTTP receiver on `:4318`: an axum middleware that rejects requests where the `Host` header is not in `{127.0.0.1:4318, localhost:4318, [::1]:4318}` (with the actual configured port). DNS rebinding works by serving a low-TTL DNS record that flips from attacker-IP to `127.0.0.1`, but the browser still sends the **attacker domain** in the `Host` header on the second request — so Host-header allowlisting breaks the attack. The OTLP gRPC receiver on `:4317` is incidentally protected because browsers cannot send raw HTTP/2 + gRPC frames; only `:4318` (HTTP/JSON path especially) needs this.
- **Source:** https://mcpsec.dev/advisories/2025-09-19-coder-chat-exfiltration/

### CORS deny-by-default (recommended for OTLP HTTP)

- **Version:** `tower_http::cors::CorsLayer` (current)
- **Last release:** Current
- **Status:** actively maintained
- **Fits because:** Companion to Host-header validation. For HTTP `:4318`, no browser context should be making OTLP calls — OTLP exporters are server-side or SDK-embedded.
