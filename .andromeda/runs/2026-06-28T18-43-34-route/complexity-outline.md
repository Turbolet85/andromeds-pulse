## Epoch outline (4 epochs)

### Epoch 1 — Foundation: AI-debug spine

- **Scope:** make the core AI-debug climax real + reproducible — the deterministic env-gated L4 mode + Tier1 incident-path reliability + wired Investigate actions, so storm→incident→Investigate fires without GPU/3B.
- **Drilldown depth:** 1
- **Estimated chunks:** 3
- **Concerns:**
  - Deterministic env-gated L4 mode (canned `L4Output` via `StubInferenceRunner`) — intent F13a / arch §LLM Inference Runtime; the keystone that unblocks Investigate + Conductor.
  - Tier1 incident-path reliability under load (coalesce identical hard-signals + elastic queue) — intent F13b.
  - Investigate actions functional (real LLM/MCP-backed analysis + progress + result) — intent F12.

### Epoch 2 — Window & shell hygiene

- **Scope:** the window behaves like a real desktop app — geometry, movability, size constraints, predictable close, no leaking browser chrome, widget→dashboard navigation.
- **Drilldown depth:** 1
- **Estimated chunks:** 5
- **Concerns:**
  - Window geometry + movable frameless titlebar (intent F1) + size constraints (intent F2) — layout-templates surfaces.
  - Predictable close + honest tray (intent F3) — arch §Tray icon policy.
  - Browser-chrome suppression: context menu (F4) + canvas image-save (F5) — merged (one webview-affordance chunk).
  - Widget→dashboard navigation affordance (intent F6).

### Epoch 3 — State honesty & legibility

- **Scope:** the UI tells the truth and is glanceable — only live services, anomalies first, labeled constellation, plain-language status, self-explaining empty states.
- **Drilldown depth:** 1
- **Estimated chunks:** 5
- **Concerns:**
  - Live-only service truth — no phantom persisted services (intent F7; HIGH PAIN; trust invariant).
  - Anomaly surfacing — errors first + flagged + filterable (intent F8; HIGH PAIN) — obs-plan anomaly highlighting.
  - Legible labeled constellation (intent F9) + plain-language status (intent F10) — design-system severity encoding + layout-templates.
  - Self-explaining empty states (intent F11).

### Epoch 4 — Polish & ship: verification

- **Scope:** prove + guard the assembled product — Conductor e2e + delegated-timing verification, an integration UX test of the real path, and dev-tool housekeeping.
- **Drilldown depth:** 1
- **Estimated chunks:** 3
- **Concerns:**
  - Conductor e2e + delegated-timing verification (P-025/P-027/P-037/P-045) against the deterministic mode (intent F14; dynamic-external).
  - Integration UX e2e test of the real assembled path (intent F15) — test-plan §6 critical-path tier.
  - Demo injector formalized + api-surface.md retirement post-tree.db (intent §5 housekeeping).
