## Constraints
- Evidence refs (span ids, exception fingerprints, `timestamps_unix_nano`) are "immutable telemetry fact" and must render in the JetBrains Mono stack — `Code` role (400 / 12px / tracking 0.5) for id strings and `Data` role (400 / 12px / tabular-nums) for numeric/timestamp values — never the IBM Plex Sans body stack (per design-system §Typography, Code + Data rows; reinforced by §Anti-Patterns → Rejected Defaults, "Sans-serif with mixed weights … for all hierarchy"). Whether the current renderer already uses `font-code`/`font-data` for these is research's question.
- The plan requires a distinct honest-error/degraded variant checked BEFORE the empty branch, "so a query failure never masquerades as 'no data'" — static message, no actionable hint, `#B4BCCB` (`--color-text-secondary`) body text (per design-system §Surface: desktop-webview → Component Patterns → Loading / Empty States). This chunk's core defect (a false-degraded verdict over a clean parse) is the same masquerade class inverted; the rendered branch selection must match the true parse state.
- Accent `#C7556A` is a **non-text** token (≈3.8:1 on Base): degraded/alert emphasis is carried as border + optional icon; body-size notice or error text must use `--color-text-primary` `#E8EEF7` (per design-system §Color Palette → "Accent usage (non-text token)").
- Body-size supporting text requires `--color-text-secondary` `#B4BCCB` (~6.8:1); Tertiary `#7D8697` (~4.2:1) is large-text-only and must not carry a body-size brief message (per design-system §Color Palette → Text Hierarchy).
- Any brief container is borders-only depth: Raised-1 `#262A33` + 1px `rgba(74,144,226,0.3)`, `radius-md` 6px, `space-md` 16px padding, `space-lg` 24px between the six sections — no shadows, no gradient/glass chrome (per design-system §Depth Strategy, §Border Radius, §Spacing).
- If the parsed-vs-degraded swap introduces any transition: entrance animations are **none**, chrome transitions capped at 150ms hover / 200ms fade, no opacity fade >200ms, and all motion must honor `prefers-reduced-motion: reduce` (per design-system §Motion → duration scale, Hard limits, Accessibility).
- All values must be tokens (`var(--color-*)`, `--spacing-*`, `--radius-*`, `--font-*`) reachable from React; raw hex or px literals fail the plan's own gate (per design-system §Surface: desktop-webview → Tokens (platform-specific); §Self-Validation Protocol → 4. Token Test).

## Patterns to follow
- Shared `EmptyState` primitive with its honest-error variant (decorative glyph `aria-hidden` + message + optional actionable hint, hint technical values in `font-code`) — reuse it for a genuinely-degraded brief rather than introducing a bespoke "_Interpretation pending_" string (per design-system §Surface: desktop-webview → Component Patterns → Loading / Empty States).
- Card/panel primitive for each brief section: Raised-1 background + subtle Earth Blue border, hover → emphasis border only, no background change (per design-system §Surface: desktop-webview → Component Patterns → Cards / Panels).
- Telemetry-table primitive if the Evidence refs render tabularly: transparent rows, JetBrains Mono 12px cells with tabular numerals, `space-sm` padding, 1px `rgba(74,144,226,0.1)` row borders, instant hover (per design-system §Surface: desktop-webview → Component Patterns → Tables).
- Custom-glyph set for any retry/investigate affordance on the degraded brief — `<Icon glyph="telescope" />` for "investigate", Lucide/Heroicons only as fallback for generic controls; icons clarify, never decorate (per design-system §Iconography).
- Secondary button pattern for a non-primary "retry interpretation" control (Raised-1 background, `#E8EEF7` text, subtle border → `#4A90E2` on hover, 150ms ease-out) (per design-system §Surface: desktop-webview → Component Patterns → Buttons).

## Anti-patterns to avoid
- **NEVER** signal degraded/anomalous state by hue alone — every color must communicate meaning paired with a text label or icon (per design-system §Anti-Patterns → Universal Bans, "NEVER use color purely for decoration"; §Color Palette accent-as-non-text).
- **NEVER** introduce hardcoded hex/px, Tailwind-default palette colors, or banned font families (Inter, Roboto, Arial, Helvetica, Open Sans, Lato, system-ui, Space Grotesk) in the touched render path (per design-system §Anti-Patterns → Universal Bans).
- **NEVER** render the narrative brief with the same layout as a data table or a status notice — a six-section interpretation, an Evidence id list, and a degradation notice are different information types (per design-system §Anti-Patterns → Universal Bans, "NEVER use the same layout for different information types").
