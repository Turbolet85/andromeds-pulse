## Constraints
- Tier **Standard (1) → WCAG 2.1 AA (~50 SCs)** with a **motion-sensitive AAA escalation to SC 2.3.3**; axe must run `runOnly` tags `wcag2a`/`wcag2aa`/`wcag21aa` plus `wcag22aa` for SC 2.5.8 target-size (per a11y-plan §1 "WCAG Criteria Mapping" + §3 "A11y testing tool pick"). Any narrowing of `runOnly` requires an explicit Decisions Log entry (per a11y-plan §11 Strategy).
- Every WCAG SC this chunk touches requires **at least one machine-verifiable path** (axe/Lighthouse/pa11y/Playwright JSON); the SR leg of the working entry's "focus/keyboard/contrast/SR" sweep is **supplemental, never sole** evidence (per a11y-plan §2 "Agent-runnable invariants" + §3 "Screen reader test pattern"). Manual SR results must still be emitted as `a11y-sr-results.jsonl` records aligned to the obs schema.
- **Semantic HTML first, ARIA second** (per a11y-plan §4 naming convention). This governs the scope's canvas/table fork: the plan §7 "Landmark roles" requires a labelled region wrapping the WebGPU canvas and names the literal `"Telemetry traces chart"`, while §1 P1/P4 + §5 + §7 record region-and-`table` as REQUIRED-but-NOT-SHIPPED with **this route entry named as owner**. The plan is target state — whether HEAD already satisfies either half (and therefore whether those four sites need amendment rather than implementation) is research's question, not something the plan can attest.
- Cell-level keyboard navigation in the trace list is deferred by a11y-plan §5 ("full-dashboard-traces") **on the stated premise that the `table` role is unshipped**; the §5 contract it defers is "Tab across cells, arrow-key drill into rows/columns". Whether that premise holds at HEAD — and thus whether §5 becomes assertable or the deferral stands — is research's question (per a11y-plan §5 + §1 P1 row).
- Universal minimums **SC 2.1.1 Keyboard / SC 2.4.3 Focus Order / SC 4.1.2 Name-Role-Value** apply across the full **P1–P12** surface set, not just P1–P7 (per a11y-plan §1 "Surface set extension"), and every path also carries its named path-specific SCs (per a11y-plan §10 "WCAG SC coverage report").
- Motion: all `--duration-fast` / `--duration-standard` / `--duration-investigation-collapse` / `--easing-*` tokens must degrade under `prefers-reduced-motion: reduce`, and the state they convey must remain readable via **color + text + focus ring**, not motion alone (per a11y-plan §6 "Motion tokens" + §1 motion-sensitive trigger). Vanilla canvas frame loops require an explicit `matchMedia('(prefers-reduced-motion: reduce)')` check — the `useReducedMotion` hook only covers React code (per a11y-plan §11 Motion). This is the binding for the data-driven Halo State Pulse.
- Focus restoration for the `findings` / `report` windows must cross window boundaries via first-party Tauri events (`findings:dismissed` / `report:closed`), **not** `focus-trap-react` `returnFocusOnDeactivate`, which cannot (per a11y-plan §5 "Focus restoration"). Selectors this chunk binds for the live drive must respect that mechanism even though the drive itself is another entry's.

## Patterns to follow
- **Per-surface axe spec, one per route/modal, added in the same chunk** — the p8–p12 specs are the named template; fixtures belong in `helpers/v02-fixtures.ts`; any new TauRPC procedure a fixture consumes is mocked via the `TauRPC__&lt;router.path&gt;` command shape (per a11y-plan §3 "Harness wiring &amp; conventions"). This is the pattern the scope's `p14` follows.
- **Suite-health check before trusting a green run**: `npx playwright test --list`, because a list-time import failure once silently disabled the whole suite (per a11y-plan §3 "Harness wiring &amp; conventions").
- **Focus-order assertion via ground truth, not hand-written order**: `tabbable(container)` computes the expected sequence, `page.keyboard.press('Tab')` + `document.activeElement` gives the actual, assert match; Esc closes modals and restores focus to the trigger (per a11y-plan §3 "Focus management test harness" + §5 "Test harness pattern").
- **Reduced-motion assertion**: `page.emulateMedia({ reducedMotion: 'reduce' })`, then assert computed `transition-duration: 0s` / `animation-duration: 0s` per the `motion-reduce:` Tailwind variants, and assert the state change survives without motion (per a11y-plan §6 "Motion tokens").
- **Not-color-alone is a custom DOM assertion, not an axe rule** — axe-core does not detect it; verify an icon or text label accompanies every state color (per a11y-plan §6 "State color tokens"). Relevant to the anomaly-control and status surfaces named in the working entry.

## Anti-patterns to avoid
- NEVER `tabindex &gt; 0`, and NEVER nest focusables inside focusables (per a11y-plan §11 Keyboard) — this bounds the P4 design call on cell-level navigation depth: roving `tabindex="0"/"-1"` is the compliant shape, an explicit positive tab order is not.
- NEVER add ARIA that duplicates inherited semantics — `role="button"` on `&lt;button&gt;`, and by the same rule `role="table"` on a native `&lt;table&gt;` or `role="region"` on a `&lt;section&gt;` that already has an accessible name (per a11y-plan §11 ARIA + §4 naming convention).
- NEVER treat manual SR/keyboard/contrast as the gate, claim conformance without machine-verifiable JSON, apply a retry-once policy, or soften the gate to a warning (per a11y-plan §11 Strategy / SLO / CI).

## Contract bindings
- **Violation JSON → obs**: every emitted violation carries `wcag_criterion` / `violation_type` / `severity` / `surface` / `selector` / `remediation` / `tool` / `tool_result_id` in the obs Section 6 log shape, with optional `token_name` / `measured_value` / `required_value` / `affected_component` (per a11y-plan §3 "Structured violation JSON schema"); artifacts land in `~/.andromeda-pulse/logs/` (per a11y-plan §1 "CI Integration").
- **CI gate → tests harness**: `npm run test:a11y` reuses the tests' 5-command E2E driver (`boot`/`run`/`status`/`cleanup`/`logs`) in the same `ci.yml` pipeline; the regression gate diffs `{surface, wcag_criterion, selector, severity}` tuples against `baselines/a11y-violations-summary.json` (per a11y-plan §3 "CI integration" + §9).
- **Contrast → design-system tokens**: the six token pairs plus `--border-focus` ≥ 3:1 are verbatim from design; token names are reproduced, never invented (per a11y-plan §6 "Color contrast pairs" + "Focus ring tokens").
- **Traces-semantics claim → test-plan**: the same gap is tracked as test-plan §1 trigger `traces-surface-a11y-semantics-absent`, so any reconciliation is a paired amendment across both plans (per a11y-plan §1 P1 row, which names this route entry as owner).
- **Amendment cascade**: the P5 accessible-name precedent shows a11y-plan changes cascade to `.claude/rules/a11y.md`, `.claude/docs/a11y-summary.md`, and the three `tests-a11y/screen-reader/a11y-sr-{nvda,orca,voiceover}.md` scripts (per a11y-plan-amendments 2026-06-30).
