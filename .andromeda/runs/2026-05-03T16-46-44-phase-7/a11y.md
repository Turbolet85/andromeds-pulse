## Anti-patterns к avoid

- NEVER rename / alias / shorten the canonical token names (e.g., `--text-primary` instead of `--color-text-primary`, or `--accent` instead of `--color-accent`) — a11y-plan §2 naming convention is the LOCKED contract that contrast harness (#12), focus harness (#13), and motion harness (#15) read by literal string (per a11y-plan §11 Universal "NEVER claim WCAG conformance without machine-verifiable evidence" — drift breaks the evidence chain).
- NEVER ship motion tokens without а `prefers-reduced-motion: reduce` override path in the same CSS file — leaving reduced-motion to "later" violates SC 2.3.3 AAA escalation and creates а phase-7 → phase-9 (chunk #15 motion library) gap where any UI work between would land non-compliant motion (per a11y-plan §11 Motion anti-patterns + design-system.md "All motion respects `prefers-reduced-motion`").
