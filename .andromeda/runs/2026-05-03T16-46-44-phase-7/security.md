## Patterns к follow

- **`'self'`-only static-asset serving**: every webview asset (CSS, font, SVG glyph) is bundled into the Tauri build output and served from the `tauri://localhost` origin — mirrors the existing `pulse-app/tauri.conf.json` CSP literal that defines `default-src 'self' ipc: http://ipc.localhost` (per security plan §API Security CSP row).
- **First-party, locally bundled, no CDN**: same shape as the WOFF2 + WGSL shader handling already implied by Cross-cutting Patterns "no CDN" — adopt for Tailwind v4 `@theme` output (single first-party CSS file) without exception (per security plan §API Security CSP row + Anti-Patterns §API row 1 default-deny CORS + arch §Cross-cutting Patterns).
- **License provenance file pattern**: each redistributed third-party asset (font, icon, vendored dep) ships its `LICENSE` / `OFL.txt` file in-tree alongside the asset so `cargo deny check licenses` and downstream Homebrew/Scoop license scans pass cleanly — follow the same convention any future `crates/*/vendor/` dir would (per security plan §Dependency Security CI integration `licenses` row).
- **Build-time-only tooling**: Tailwind v4 + PostCSS + font-conversion tools are dev-dependencies / build-time tools, never linked into the shipped binary — keeps the Minimal-tier "no runtime CDN / no runtime fetcher / no runtime asset transform" posture intact (per security plan §Threat Model Summary attack-surface "webview content (host-side)" trust boundary).

## Anti-patterns к avoid
