## Anti-patterns к avoid

- NEVER apply gradient overlays, glassmorphic backdrop blur, or drop-shadows to the footer band or aggregated badge container — flat matte surfaces with intentional color blocking are mandatory; the WebGPU Halo (radial gradient + blur) is the ONLY exception, and it lives on its dedicated canvas layer, not on the chrome (per design-system.md §Anti-Patterns Universal Bans + §Depth Strategy).
- NEVER convey error state via background color alone (e.g., turning the entire footer red on errors) — pair `--color-accent` with text/icon affordance; pure color encoding violates the "NEVER use color purely for decoration" Universal Ban and the "color + text label" semantic (per design-system.md §Anti-Patterns Universal Bans + §Color Palette Semantic Colors table — Error row uses `--color-accent` border + Primary text body).
