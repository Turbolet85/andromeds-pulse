## Constraints

- The compact widget titlebar MUST be 32px height, contain app icon (16px), title text "andromeda-pulse", settings button (aperture icon, 20px), and window controls positioned per platform convention (Windows/Linux: right-aligned; macOS: traffic-light left-aligned). Drag region spans full titlebar width excluding buttons. (per design-system.md §Surface: desktop-webview Component Patterns §Navigation / App Shell)
- The compact widget background MUST use `--color-base` (#1A1D24, Deep Control Gray) as the window surface. Elevated chrome elements (if any) use `--color-raised-1` (#262A33) with 1px border `rgba(74, 144, 226, 0.3)`. No shadows; depth via color + border only. (per design-system.md §Color Palette §Surface Scale and §Depth Strategy)
- Frameless window MUST be configured via Tauri `"decorations": false`. Custom titlebar renders all OS window controls in React webview, not OS chrome. (per design-system.md §Surface: desktop-webview §Platform-Specific Notes)
- Spacing within the titlebar and widget chrome MUST use design tokens: `--spacing-xs` (4px), `--spacing-sm` (8px), `--spacing-md` (16px) — no magic pixel values. Base unit is 4px; all values must be multiples thereof. (per design-system.md §Spacing)
- Border radius for the titlebar or any panel elements MUST use token values: `--radius-sm` (4px) for controls, `--radius-md` (6px) for panels. No hardcoded pixel values. (per design-system.md §Border Radius)
- Focus ring on all interactive titlebar controls (settings button, window control buttons) MUST use 3–4px outset, color #4A90E2, rendered via `box-shadow: 0 0 0 3px rgba(74, 144, 226, 0.2)` or `outline: 3px solid #4A90E2`. `:focus-visible` applies to all focusable elements. (per design-system.md §Surface: desktop-webview §Focus / Keyboard Navigation)
- Titlebar chrome transitions (hover, focus) MUST use `--duration-fast` (150ms) `ease-out`; NO opacity fades longer than 200ms; NO spring physics, bounce, parallax, or scroll animations. (per design-system.md §Motion Hard limits at expression 0.35)

## Patterns к follow

- Compact widget navigation pattern: settings icon in titlebar → Settings panel; keyboard navigation via Tab through titlebar controls; Esc to minimize/focus loss. (per design-system.md §Surface: desktop-webview §Navigation Pattern §Compact widget)
- Settings button uses the **aperture** custom SVG glyph (`<Icon glyph="aperture" />`), registered at `src/components/icons/`. Icon size 20px with 6px padding in its container. Fallback to Lucide/Heroicons ONLY if domain-specific glyph is unavailable — the custom set is primary. (per design-system.md §Iconography)
- Typography in the titlebar title uses IBM Plex Sans 14px weight 400 (Body role) or 12px weight 500 (Label role) — NOT JetBrains Mono (which is reserved for immutable telemetry data values). (per design-system.md §Typography)
- Canvas container for the Halo State Pulse (successor chunk #31, but shell must reserve space for it) uses `--color-inset` (#0F1117) background — recessive, allows halos to pop. Dimensions responsive to container (full widget width/height). (per design-system.md §Surface: desktop-webview §Component Patterns §Canvas Container)

## Anti-patterns к avoid

- NEVER use gradient overlays, glassmorphic effects, or box shadows on the widget chrome. Flat matte surface with border-only depth is the discipline; the Halo State Pulse canvas (chunk #31) is the sole exception for visual weight. (per design-system.md §Anti-Patterns §Universal Bans and §Depth Strategy)
- NEVER ship visible Chromium/WebView2 artifacts: no context menu on right-click, no browser-default text selection on the titlebar or icon elements, no URL bar. (per design-system.md §Anti-Patterns §Per-Surface Bans desktop-webview)
- NEVER use hardcoded hex or pixel values for any visual property — all colors, spacing, and radii must trace to `@theme` CSS custom properties in the Tailwind v4 config. (per design-system.md §Surface: desktop-webview §Tokens)

## Contract bindings

(per design-system.md §Motion §Accessibility)

(per design-system.md §Downstream Readiness §For tests specialist)
