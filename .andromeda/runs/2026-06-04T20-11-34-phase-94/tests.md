## Anti-patterns to avoid
- NEVER add `#[cfg(test)] mod tests` to `pulse-app/src/` for the new resolver tests — they will silently never run under nextest (verify any pulse-app test actually runs via `cargo nextest list -p pulse-app | grep <name>`); use `pulse-app/tests/` integration crates (per testing.md Session Additions 2026-05-20).
- NEVER include visual-regression / pixel inspection / human-approval steps for sparkline/history-chart rendering — assert IPC contract + DOM structure + text alternative presence; canvas/SVG pixel output is out of agent-driven scope (per test-plan §11 Universal: no Percy/Chromatic, §6 agent-driven discipline).
- NEVER assert backoff-countdown / last-span-ago / 30-day-window using real wall-clock — inject time; otherwise the test is flaky and violates the zero-flakiness budget (per test-plan §10 Zero-flakiness, §11 Universal "NEVER use real time").
