- NEVER widen the `pulse:default` capability JSON to add Tauri core APIs (`fs`, `shell`, `dialog`, `http`) for Halo-related chrome — Halo is a pure WebGPU render component and should not need any new Tauri core API grant (per security plan §Security Anti-Patterns API "NEVER grant Tauri core APIs to `pulse:default`...").
