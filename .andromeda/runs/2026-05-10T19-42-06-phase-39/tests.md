## Patterns to follow

- React 19 useEffect-driven mock count assertions: use `toHaveBeenCalled()` (≥1 call) rather than `toHaveBeenCalledTimes(N)` because React 19 dev-mode useEffect double-invocation makes strict counts fragile when effects depend on async-resolved state (per `.claude/rules/testing.md` §Session Additions 2026-05-08).
- Vitest global stub hygiene: any test that stubs `navigator.*`, `window.*`, or other global properties MUST call `vi.unstubAllGlobals()` in per-test-file `afterEach` — `pulse-app/ui/src/test-setup.ts` only handles `@testing-library/react` cleanup, not Vitest globals (per `.claude/rules/testing.md` §Session Additions 2026-05-08).
- Tauri webview-API mock pattern for chunks consuming `@tauri-apps/api/*`: `vi.mock("@tauri-apps/api/<module>", () => ({ <fn>: vi.fn() }))` at top of test file (vi.mock hoists before imports), then per-test `vi.mocked(<fn>).mockReturnValue(...)` with type-cast escape; reset via `vi.mocked(...).mockReset()` in `afterEach` (per `.claude/rules/testing.md` §Session Additions 2026-05-09 chunk #32 use-window-label pattern).
- `vi.hoisted` ownership for mocks referencing external state: `const mocks = vi.hoisted(() => ({ fn: vi.fn() })); vi.mock("module", () => ({ ... mocks.fn ... })); const { fn } = mocks;` — top-level `const` referenced inside a `vi.mock` factory triggers `ReferenceError: Cannot access ... before initialization` (per `.claude/rules/testing.md` §Session Additions 2026-05-09 chunk #33).
- focus-trap-react in jsdom: when chunk wires focus trap (likely if Investigate trigger opens a "supporting moment" overlay with a11y trap), test MUST set `focusTrapOptions.tabbableOptions.displayCheck: 'none'` to bypass jsdom's 0×0 layout (per `.claude/rules/testing.md` §Session Additions 2026-05-09 chunk #33 CommandPalette pattern).
- `tabbable(container)` for focus inventory assertions: import from `tabbable` 6.4.x (already a workspace dep) to assert focusable-element count without enumerating selectors; works in jsdom because it reads `tabIndex`/`disabled`/element-type rather than computed layout (per `.claude/rules/testing.md` §Session Additions 2026-05-09 chunk #32 CompactWidget pattern).
- TauRPC-fetch loading-gate testing: when a control's `isDisabled={loading}` is gated on async fetch, after `findByLabelText(...)` additionally `await waitFor(() => expect(...data-disabled...).toBeNull())` BEFORE clicking — react-aria-components `Button` intercepts press handlers when disabled, causing `userEvent.click()` to no-op (per `.claude/rules/testing.md` §Session Additions 2026-05-10 chunk #38).
