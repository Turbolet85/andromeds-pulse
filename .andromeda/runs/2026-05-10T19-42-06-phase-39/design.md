## Constraints

- Investigate button is the canonical "Generate Snapshot" Primary action — primary button styling MUST use `--color-primary` (#4A90E2) background + `#1A1D24` (Base) text + `--radius-sm` (4px), padding `--spacing-sm` (8px) horizontal + `--spacing-xs` (4px) vertical, with hover transition 150ms ease-out raising background to `#5BA5F0` and focused outline 3px `#4A90E2` (per design-system.md §Surface: desktop-webview Component Patterns Buttons).
- Investigate trigger MUST use the custom `<Icon glyph="telescope" />` glyph at 20px (button-row size) — the telescope glyph is the locked semantic for "investigate" (instrument of observational astronomy → deep inspection of distant services). Library/Lucide fallback is a Universal Ban (per §Iconography Primary custom set + §Anti-Patterns Rejected Defaults).
- Capture Collapse supporting moment MUST be 350ms scale + opacity ease into a centered snapshot object (NOT exceeding the supporting-moment ceiling, NOT shorter than 250ms — exempt from the 200ms chrome hard limit because it is one of the 2 high-impact moments allowed at 0.3–0.35 expression) (per §Motion Supporting moments + §Motion High-impact moments item 2).
- Capture Collapse MUST respect `prefers-reduced-motion: reduce` — the 350ms scale+opacity transition collapses to 0ms (instant) when reduce is set; the visual confirmation falls back to a state change (e.g., aria-live announcement + static "Snapshot ready" surface) without animation (per §Motion Accessibility).
- Trace-row right-click context menu MUST NOT use the browser-native context menu — webview must suppress `contextmenu` event and render a styled custom menu using Card pattern (`--color-raised-2` #2D3139 background, 1px subtle border `rgba(74,144,226,0.3)`, `--radius-md` 6px) (per §Anti-Patterns Per-Surface Bans desktop-webview "NEVER ship with visible Chromium/WebView2 artifacts (context menu...)").
- Compact widget Investigate trigger MUST honor information-architecture discipline: every pixel counts at quarter-screen size; if button does not earn its place, prefer the icon-only `<Icon glyph="telescope" />` 20px hit-target (per §Iconography Rule "Icons clarify, not decorate" + §Brand Identity desktop-webview compact widget framing).

## Anti-patterns to avoid

- NEVER use bounce easing or spring physics on the 350ms Capture Collapse — contemplative tone rejects "delightful" framing in favor of state-confirming motion; ease-in-out scale+opacity only, no overshoot (per §Motion Easing + §Anti-Patterns Rejected Defaults "Animated state transitions using bounce easing").
- NEVER communicate Investigate's pressed/busy/disabled state with color alone — pair `--color-primary` background change with the telescope icon state and a text/aria-label change (e.g., "Investigate" → "Capturing…") (per §Anti-Patterns Universal Bans "NEVER use color purely for decoration" + Color Palette Decisions Log 2026-05-03 not-color-alone discipline).
- NEVER use `alert()` / `confirm()` / browser-native context menu / hover-only Investigate (no keyboard alternative) — all 4 trigger surfaces must be Tab-navigable with `:focus-visible` ring; right-click must trigger styled menu, not browser default (per §Anti-Patterns Per-Surface Bans desktop-webview).
