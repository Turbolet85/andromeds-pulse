## Anti-patterns to avoid

- NEVER ship a built-in template that uses generic fonts (Inter, Roboto, Arial, Helvetica, Open Sans, Lato, system-ui default, Space Grotesk) as primary — JetBrains Mono + IBM Plex Sans are the locked choices (per design-system.md §Anti-Patterns Universal Bans row 1).
- NEVER ship a built-in template that uses Tailwind default palette colors or purple-gradient brand identity — the NASA Deep Space Mission Control palette (#1A1D24 / #4A90E2 / #C7556A / #E8EEF7 / #2C3E7F / #17B3A3) is the single source of truth (per design-system.md §Anti-Patterns Universal Bans row 2).
- NEVER ship a built-in template demonstrating gradient overlays, glassmorphism, drop-shadows, hover bounce easing, or 500ms+ "delightful" transitions — flat matte chrome with borders-only depth is the discipline (per design-system.md §Anti-Patterns Universal Bans row 3 + §Anti-Patterns Rejected Defaults "Animated state transitions using bounce easing and 500ms+ durations").
