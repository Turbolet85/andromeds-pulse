The refactor preserves this by switching inputs from `errorRate`/`throughputHz` to `cumulativeSeverity`/`connectionState` — still real-time observable data. - **Shared shader logic across surfaces**: compact widget + full dashboard + tray icon all use the same WebGPU shader path (and SVG-filter fallback for tray). The existing pattern is single-source shader (halo.wgsl) consumed by all three surfaces — the refactored shader must remain the single source. (per layout-templates.md §Component — Halo State Pulse canvas Canvas rendering: "blur radius envelope per pulse cycle ... opacity envelope per pulse cycle" — no scale mentioned)
