### Universal warnings (top 10 — selected by severity priority security > a11y > obs > tests > design)

1. **OTLP receivers bind to `127.0.0.1` ONLY** — loopback is the de-facto authorization boundary (no auth model). Never `0.0.0.0` or any non-loopback interface; `tonic` server config + `axum` middleware must reject. Negative test enforces. *(security plan §API Security + §Anti-Patterns Universal)*
2. **DuckDB queries use prepared statements with `?` placeholders** — never `format!("SELECT … WHERE service_name = '{}'", user_input)`. The 2026 DuckDB CVE cluster (Dagster GHSA-mjw2-v2hm-wj34, Vanna CVE-2024-5827, dagster-duckdb CVE-2026-41490) is the dominant injection class; DuckDB explicitly warns "treat SQL like Bash code." *(security plan §Anti-Patterns Input)*
3. **Post-`prost` OTLP invariants required** — `prost` only validates wire format. Ingest crate must check `span_id` is 8 bytes, `trace_id` is 16 bytes, attribute keys/values bounded BEFORE handing batches to `buffer::Appender`. *(security plan §Anti-Patterns Input)*
4. **Path env vars canonicalize via `strict-path`** — every `ANDROMEDA_PULSE_*_PATH` / `*_DIR` env var must `Path::canonicalize()` + assert the resolved path lives under the resolved data dir. CWE-22 path traversal class defense. *(security plan §Anti-Patterns Input + Code Patterns)*
5. **Tauri capabilities are negative-default — every TauRPC procedure needs `pulse-app/capabilities/` JSON entry** — adding a procedure to a router without the capability addition produces a silent runtime rejection. The `xtask capability-drift` check enforces. *(security plan §API Security + arch §Cross-cutting Patterns Webview IPC capability policy)*
6. **Self-observation NEVER dials own OTLP** — product IS the local observer. `tracing` ecosystem only (`tracing` 0.1 + `tracing-subscriber` JSON + `tracing-appender` daily file sink + `tracing-error` SpanTrace); NO OTel SDK linked into self-runtime. A network exporter pointed at own `:4317`/`:4318` is infinite recursion. *(arch §Cross-cutting Patterns Self-observation + obs plan §3)*
7. **No raw OTLP attribute leakage in logs / snapshots / MCP responses** — telemetry can incidentally contain secrets, IDs, URLs, SQL fragments from instrumented host apps. Vector 1 / 4 / 5 of security plan: never log raw attrs, never log MCP tool response bodies, never log DuckDB query parameters (use `query_id` + `param_count`); never log full plugin paths (basename only). *(security plan §Logging + obs plan §Anti-Patterns Logs)*
8. **Pin third-party GitHub Actions by 40-char SHA** — never `@v2` or floating tag. `tj-actions/changed-files` CVE-2025-30066 (23k repos) is the retroactive-tag-rewrite anchor. Apply to every Action: `<owner>/<repo>@<40-char-SHA> # vX.Y.Z`; Dependabot bumps SHA + comment together. *(security plan §Anti-Patterns Secrets + §Bootstrap dep-security-ci-gate)*
9. **AppError sanitization at TauRPC bridge** — convert `thiserror`/`anyhow` to the `serde`-friendly `AppError` enum (`Validation { field, reason }` / `NotFound { resource }` / `Internal { message }` / `Plugin { plugin_id, message }` / `Storage { message }` / `Ingest { message }`). Strip stack traces, file paths, library versions, Rust struct names. *(arch §Conventions Error response schema + security plan §Error Handling)*
10. **Reduced-motion respect is mandatory** — every transition (chrome AND data-driven) must degrade per `prefers-reduced-motion: reduce`. Halo State Pulse becomes static glow (hue still updates per error rate). Lighthouse a11y audit + Playwright `page.emulateMedia({ reducedMotion: 'reduce' })` enforce. *(a11y plan §Triggers motion-sensitive + WCAG 2.1 AAA SC 2.3.3)*

## Agent harness

Development Style=agent-driven → materialize harness:

- `scripts/agent-run.sh` (POSIX shell) — 5 commands wired to test-plan §3 + obs-plan §3:
  - `boot`: `cargo run --bin pulse-app --release` + env `ANDROMEDA_PULSE_DATA_DIR=$TMPDIR/...` + `RUST_LOG=debug`; poll TauRPC `health` every 500ms up to 10s; assert `status == "ok"`
  - `run`: `cargo nextest run --workspace --profile ci --message-format libtest-json`
  - `status`: invoke TauRPC `health` via test client; parse `{ status, subsystems, uptime_ms, pid }`
  - `cleanup`: `kill -TERM $(cat $PID_FILE)`; verify ports `:4317`/`:4318` released; SIGKILL escalation
  - `logs`: `cat ~/.andromeda-pulse/logs/agent-latest.jsonl` (or fallback chain via `ANDROMEDA_PULSE_DATA_DIR`)
- `scripts/agent-run.ps1` (PowerShell variant) — same 5 commands using PowerShell idioms
