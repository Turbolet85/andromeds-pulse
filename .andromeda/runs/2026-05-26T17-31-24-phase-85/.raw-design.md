- Button primitives per Component Patterns (Primary `#4A90E2` background + `#1A1D24` text + `space-sm`/`space-xs` padding + `radius-sm` for copy-markdown CTA; Secondary `#262A33` + Primary text for section-collapse toggles) — focus ring 3px outset `#4A90E2` mandatory (per design-system §Surface: desktop-webview §Buttons + §Focus / Keyboard Navigation).
- Tables Component Pattern для Telemetry Excerpts (anonymized) and Evidence sections: row background transparent (parent shows through), hovered row `rgba(74, 144, 226, 0.1)` instant change (no transition per 0.35 expression discipline), header background `#1A1D24` + IBM Plex Sans 600 12px, data cells JetBrains Mono 12px tabular-nums + `space-sm` padding (per design-system §Surface: desktop-webview §Tables).
- Iconography composition: any section glyph SHOULD prefer the custom set first — `aperture` (for "view settings" / metadata icons), `telescope` (for "investigation steps" section header — domain anchor: instrument of observational astronomy), `constellation-grid` (for "project context" service map references), `star` (for "Previously seen" cross-incident bookmark subsection); Lucide/Heroicons fallback only when domain-specific glyph absent. Sizing follows §Iconography Size Grid: 16px inline labels / 20px buttons / 24px section headers (per design-system §Iconography).
- Empty / loading / error states (e.g., LLM still processing / report not yet generated / fetch failure): use existing skeleton pattern (Raised-1 background + opacity pulse animation `pulse 1.2s ease-in-out infinite` per §Loading/Empty), empty-state centered Tertiary text `#7D8697` с optional telescope icon, error state Alert Burgundy `#C7556A` text + icon + one-or-two-line message (per design-system §Component Patterns §Loading / Empty States).

## Anti-patterns к avoid

- NEVER introduce gradients, glassmorphism, or shadows on the Report panel chrome — flat matte surfaces only с borders-only depth strategy per design-system §Depth Strategy + §Universal Bans (Halo State Pulse remains the ONLY canvas/gradient exception, which is not part of the Report surface).
- NEVER use color alone к convey severity / state on Report sections (e.g., red text without "High severity" label, green border without "Resolved" word, color-tinted hypothesis cards without an icon or written tag) — every semantic-color application MUST be paired с а text label or icon per §Universal Bans "NEVER use color purely for decoration" + §Semantic Colors row discipline.
- NEVER use banned generic fonts (Inter / Roboto / Arial / Helvetica / Open Sans / Lato / system-ui / Space Grotesk) anywhere in the Report markdown serializer's HTML rendering or fallback chain — JetBrains Mono + IBM Plex Sans are the locked choices (per design-system §Anti-Patterns Universal Bans). The markdown serialization to clipboard does not need fonts; the React-rendered preview MUST.
- NEVER use `alert()` / `confirm()` / `prompt()` для the "report ready" / "report copied" / "no incident selected" surfaces — use styled inline confirmations or modal primitive (per design-system §Per-Surface Bans desktop-webview).
- NEVER apply opacity fades > 200ms on chrome (e.g., long-running section-collapse animations) — feels sluggish at 0.35 expression; section reveal/collapse capped at 200ms standard fade per §Motion Hard Limits.
