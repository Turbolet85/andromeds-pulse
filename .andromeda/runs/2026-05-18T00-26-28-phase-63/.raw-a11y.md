- NEVER add a custom keyboard shortcut for manual override (e.g., "Press D to mark dormant") without Esc/Enter/Space natural-pattern coverage — creator brief does not request custom shortcuts (per a11y plan §5 Per-surface keyboard shortcuts).
- NEVER omit focus styles on override action buttons — `--border-focus` token outline must apply on `:focus-visible` (per a11y plan §11 Keyboard row 2 + §6 Focus ring tokens — SC 2.4.7 + SC 1.4.11).
- NEVER announce every `pulse://stream/service-lifecycle` broadcast event via `aria-live` — only user-initiated overrides or critical state changes (e.g., service moved to Archived) should announce; passive system-driven transitions (e.g., Active→Quiet on idle) should NOT spam the SR (per a11y plan §11 Screen Reader row 2 — excessive ARIA noise).
