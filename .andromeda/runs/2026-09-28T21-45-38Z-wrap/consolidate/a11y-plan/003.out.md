## 2026-06-30-widget-to-dashboard-navigation — P5 button accessible name: "Expand to dashboard" → "Toggle dashboard"
**Section:** §1 Critical Paths (P5 row).
**Change:** The compact-widget's dashboard-navigation affordance is `<button aria-label="Toggle dashboard">` (opens the dashboard if hidden / hides it if visible; the glance widget always stays visible) — was `<button aria-label="Expand to dashboard">` (expand-and-hide). P5 row's button label + focus-management note updated: the toggle never hides the widget; the same handler is bound to Cmd/Ctrl+Shift+P in both windows.
**Why:** Live dogfood (2026-06-30) showed the planned expand-and-hide stranded the user with no way back to the widget; reframed to a toggle that keeps the widget always visible, so the accessible name changed and the P5 body's label was stale (P-066).
