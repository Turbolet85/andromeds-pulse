## Patterns to follow

- **Canvas semantic wrapper pattern:** `<region role="region" aria-label="...">` (or `<section aria-label>`) wraps `<canvas>`; per-chart `aria-label` differs by surface (trace timeline / flamegraph / metrics chart) — referenced from a11y plan §7 Landmark roles + §1 critical path P1 ARIA roles.
- **WebGPU adapter detection fallback pattern:** when `navigator.gpu === undefined` OR `requestAdapter()` returns null, render a semantic fallback (`<div role="alert" aria-live="assertive">` with explanatory text + remediation hint) — aligns with a11y plan §7 Live regions table "Alert (blocking)" pattern + §3 violation JSON `severity: critical` for fallback signaling.
- **Reduced-motion canvas loop pattern:** read `useReducedMotion()` (motion/react 12.x) at component mount; when `true`, skip the `requestAnimationFrame` loop and render a single static frame — per a11y plan §3.5 Bootstrap "motion-tokens-respect-install" + §6 Motion tokens verification.
- **Token-pair contrast pattern for in-canvas text:** read tokens via `getComputedStyle(document.documentElement).getPropertyValue('--color-text-primary')` at canvas-init time; pass to WGSL uniforms; never hardcode RGB literals in shaders — aligns with a11y plan §3 Contrast verification harness "reading design tokens directly via `window.getComputedStyle`".
- **Chart-text DOM mirror pattern:** for every text label rendered inside the canvas (axis ticks, series labels, hover tooltip values), provide a sibling `<table>` / `<dl>` / `aria-describedby` summary so SR users get equivalent content — referenced from a11y plan §1 critical path P1 "`table` (trace list below chart)" complementing the canvas region.

## Anti-patterns to avoid

- NEVER convey chart state by color alone in WGSL shaders (e.g., red bars for errors, green for success) without paired text/icon DOM supplement — SC 1.4.1 violation (per a11y plan §11 Anti-Patterns Visual + §6 State color tokens "(not-color-alone)").
