- Render pipeline animations (entrance, layout transitions for chart elements) MUST respect `prefers-reduced-motion: reduce` — degrade to instant render with hue still updated per data, per §Motion Accessibility (mirrors Halo State Pulse degradation pattern).
- Fallback message styling MUST use empty/error state tokens: centered text in `--color-text-tertiary` (#7D8697) with optional telescope icon (24px, same color), per Surface: desktop-webview Component Patterns §Loading / Empty States.

- Halo State Pulse measurement-intent hook (frequency Hz + LCH color state per pulse) is reserved at this layer — chunk #28 establishes the canvas/pipeline that chunk #31 will consume; emission contract belongs to obs but the pipeline must support per-frame metric emission, per §Downstream Readiness "For obs specialist".

## Patterns к follow

- Canvas Container pattern: `<canvas>` with `--color-inset` background + responsive width/height to container + free aspect ratio (chart determines shape), per Surface: desktop-webview Component Patterns §Canvas Container.
- Empty/Error state pattern for fallback message: centered text + optional 24px monochrome icon (telescope glyph viable per Iconography custom set), color `--color-text-tertiary`, per Component Patterns §Loading / Empty States.
- Token resolution pattern: consume Tailwind v4 `@theme` CSS custom properties via `var(--color-X)` — never hardcode hex in WGSL shaders or JS rendering code; pass color tokens into shaders via uniforms read from CSS computed-style at init, per Surface: desktop-webview §Tokens (platform-specific).
- Performance/render isolation pattern: charts render directly to canvas, NOT inside React's render tree — Arrow data is pushed into canvas via WebGPU, side-stepping VDOM diffing cost, per Surface: desktop-webview §Performance notes.
- LCH-based color interpolation for any chart hue gradients (e.g., latency heatmap, metric severity bands) follows the Halo State Pulse Earth Blue ↔ Alert Burgundy interpolation precedent, per §Brand Identity Signature element.

## Anti-patterns к avoid

- NEVER use canvas/WebGL outside the Halo State Pulse + WebGPU chart pipeline established here — chunk #28's three named pipelines (trace timeline, flamegraph, metrics charts) plus chunk #31's Halo are the complete enumeration, per §Motion Hard limits.
- NEVER use gradient overlays or glassmorphic effects on chart chrome (axis labels, legends, tooltips) — flat, matte surfaces with intentional color blocking are the discipline; the radial-gradient + blur exception applies ONLY to the Halo State Pulse signature element, per §Anti-Patterns Universal Bans.
- NEVER use generic font families (Inter, Roboto, Arial, Helvetica, Open Sans, Lato, system-ui default, Space Grotesk) for canvas-rendered text labels — JetBrains Mono + IBM Plex Sans are the locked choices and apply to in-canvas typography too, per §Anti-Patterns Universal Bans.
- NEVER use color purely for decoration in chart rendering — every color in the palette communicates meaning (Earth Blue = healthy, Alert Burgundy = anomaly, etc.); chart hues MUST encode data semantics, per §Anti-Patterns Universal Bans.

## Contract bindings

- **design ↔ a11y (motion)**: WebGPU render pipeline animations bind to a11y SC 2.3.3 reduce-motion override — chunk #28 must expose a `prefers-reduced-motion` query path before render-loop scheduling so chart entrance / layout transitions degrade to instant; mirrors Halo State Pulse degradation pattern (hue still updates per data, animation suppressed) per §Motion Accessibility + design focus guide §Cross-domain bindings.
- **design ↔ a11y (contrast)**: Canvas-rendered text on `--color-inset` (#0F1117) background must satisfy contrast targets — Primary text #E8EEF7 on Inset #0F1117 ≈ 9.7:1 (clears WCAG AA/AAA); axis tick labels using Tertiary #7D8697 on Inset are ≈ 4.7:1 (large-text only zone — chart axis labels at 12px require Primary or Secondary unless explicitly large-text), per §Color Palette §Text Hierarchy + §Downstream Readiness "For a11y specialist".
- **design ↔ obs (Halo measurement-intent)**: WebGPU pipeline must support per-pulse-cycle emission of frequency (Hz) + LCH color state — chunk #28 establishes the substrate; chunk #31 wires Halo State Pulse atop it; obs configures the measurement backend independently, per §Downstream Readiness "For obs specialist".
- **design ↔ a11y (not-color-alone for fallback)**: WebGPU fallback message conveys state via TEXT ("WebGPU not supported in this browser") + optional icon — never via color alone (red/yellow indicator without text), per §Anti-Patterns Universal Bans (color decoration ban) + a11y SC 1.4.1 binding.
- **design ↔ tests**: Token usage in WGSL shader uniforms + canvas container styling is lintable against Color Palette + Spacing + Border Radius tables; banned-fonts / banned-effects lints from Anti-Patterns extend to canvas-rendered content, per §Downstream Readiness "For tests specialist".
