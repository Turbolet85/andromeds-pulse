- **NEVER emit per-row `tracing::info!` from ANY new aggregation path** (obs-plan §11 Spans/Traces "over-instrument" + Logs "spam"); single event per query with `row_count`, `service_count`.
- **NEVER use unbounded label cardinality on metric events from the constellation map** beyond the obs-plan §5 §service_name exception — constellation hover state, table row index, sort direction enum: all bounded; trace_id never appears as a label.
