## Anti-patterns to avoid

- NEVER hardcode hex values, pixel values, font names, or duration numbers in the trace table or constellation components — every visual value must trace to a design token (`var(--color-*)`, `var(--spacing-*)`, `var(--radius-*)`, `var(--font-*)`, `var(--duration-*)`, `var(--easing-*)`) per the Tailwind v4 `@theme` block in design-system.md §Surface: desktop-webview Tokens (per §Anti-Patterns Universal Bans + §Self-Validation Protocol Token Test).
- NEVER encode trace error state with color alone (e.g., red text in the Error column with no icon/badge/text variation). Pair `var(--color-accent)` border or `<Icon>` glyph with the count text; nonzero error counts may also use a state badge with text label "Errors" (per design-system.md §Anti-Patterns Universal Bans "NEVER use color purely for decoration" + Decisions Log 2026-05-03 non-text token classification).
- NEVER add gradient overlays, glassmorphism, drop shadows, parallax, scroll animations, spring physics, bounce easing, staggered reveals, 3D transforms, or opacity fades > 200ms to the trace table or chrome around the constellation map. The radial-gradient + blur of the Halo State Pulse is the SOLE canvas-exception (per design-system.md §Anti-Patterns Universal Bans + §Motion Hard limits).
- NEVER substitute uniform monochrome status icons (green checkmark / red X) for the per-service Halo dots — Halo encodes TWO independent dimensions (rhythm = throughput, hue = error rate). Replacing with on/off glyphs collapses the brand signature and fails the Self-Validation Protocol §Signature Test (per design-system.md §Rejected Defaults).
- NEVER use generic stock icons (Lucide telescope, Heroicons binoculars) instead of the registered custom `<Icon glyph="telescope" />` / `<Icon glyph="constellation-grid" />` from `src/components/icons/` — custom Observatory glyphs are the primary visual language; library icons are fallback only (per design-system.md §Iconography + §Rejected Defaults).
- NEVER use sans-serif (IBM Plex Sans) for telemetry data values (trace_id, span_id, latency μs/ms, error counts) — monospace JetBrains Mono with tabular numerals encodes the spectroscopy "immutable telemetry fact" semantic and is required for column alignment (per design-system.md §Typography Code/Data rows + §Rejected Defaults).

## Contract bindings

- **Design ↔ a11y**: Color contrast — table header `--color-text-primary` #E8EEF7 on `--color-base` #1A1D24 ≈ 8.5:1 (AAA), data cells on `--color-raised-1` #262A33 transparent-row ≈ similar AAA, hovered-row text on `rgba(74,144,226,0.1)` overlay must remain ≥ 4.5:1 (a11y verifies via colorjs.io harness). Error-state `--color-accent` #C7556A on `--color-base` ≈ 3.8:1 (Decisions Log 2026-05-03) — clears non-text SC 1.4.11 (3:1) and SC 1.4.3 large-text but NOT normal-text 4.5:1, so error count text must use `--color-text-primary` with accent only on border/icon (a11y owns final WCAG conformance).
- **Design ↔ a11y**: Motion — `prefers-reduced-motion: reduce` override mandatory on BOTH chunk #34 surfaces: chrome transitions (row hover instant, sort-toggle instant, focus ring static) AND data-driven Halo State Pulse (rhythm freezes to static glow, hue continues to shift per error rate). Binding mirrors the universal invariant in CLAUDE.md §Critical Warnings ("Every transition (chrome AND data-driven Halo State Pulse) MUST respect prefers-reduced-motion: reduce") and design-system.md §Motion Accessibility — a11y owns axe-core/Lighthouse SC 2.3.3 AAA verification.
- **Design ↔ a11y**: Use of Color (SC 1.4.1 not-color-alone) — Error column state, sortable header sort-direction indicator, and per-service Halo dot state ALL must convey state via shape/icon/text in addition to color. Halo dot color (Earth Blue ↔ Alert Burgundy) is paired with rhythm (pulsing rate visible as motion) so total state encoding is dual-channel; reduced-motion mode collapses rhythm to static — a11y must verify state remains discernible without motion (e.g., dot radius or attached service-name label still encodes operational health).
- **Design ↔ obs**: Halo State Pulse measurement-intent hook — obs logs final clamped Halo pulse frequency (Hz) and color state (Earth Blue / Alert Burgundy / interpolated LCH) per pulse cycle, per service. Chunk #34 extends from chunk #31's single-service emission to N-service per-cycle emission. Obs does not re-clamp; design-side data-viz layer clamps to 0.8–2.4 Hz before emission (per design-system.md §Downstream Readiness "For obs specialist").
- **Design ↔ tests**: Token-usage lint targets — chunk #34 components must pass `.claude/rules/design-tokens.md` no-hardcoded-hex / no-hardcoded-px / no-banned-fonts checks. Tests verify Component Pattern hex (#262A33 / #1A1D24 / rgba(74,144,226,0.1) / etc.) and spacing values trace to `@theme` tokens; banned-fonts check ensures no Inter/Roboto/Arial/Helvetica/Open Sans/Lato/system-ui/Space Grotesk leakage (per design-system.md §Downstream Readiness "For tests specialist" + §Anti-Patterns Universal Bans).
