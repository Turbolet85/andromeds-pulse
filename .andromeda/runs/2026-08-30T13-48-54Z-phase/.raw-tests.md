- **Obs-allowlist boundary pins in `pulse-app/tests/*.rs`** (the 130 `observability.rs` pins now live at `pulse-app/tests/observability_pins.rs`) as the committed guard that a new leaf permits exactly the intended bounded fields (per test-plan §2 Directory pattern amendment 2026-08-30-diagnostics-un-muting-harness-truth-sweep + §1 pending-trigger precedents).

## Anti-patterns to avoid
- NEVER bind the new stage/assertion to an xpath or a hashed/utility class, and NEVER `sleep(N)` to wait for the record — wait on an explicit signal (per test-plan §11 E2E).
- NEVER let test output or the asserted record carry payload/PII/secret content — assertions must be over bounded fields only (per test-plan §11 Universal → "NEVER expose secrets in test output").
- NEVER let a one-time live observation stand in as the per-run gate for the new mechanism; if the committed guard cannot land in-chunk, the gap is minted as a §1 pending coverage trigger rather than claimed as coverage (per test-plan §1 Pending coverage triggers, the `*-wiring-coverage` class).

## Contract bindings
- **obs ↔ tests:** the record's leaf name/schema is obs-owned; test-plan §3 Log format + `logs` verb own how it is read — NDJSON `tracing` JSON lines, resolved as the ROTATED family `agent-latest.jsonl*` across three precedence-ordered bases (a bare-name reader silently finds nothing). Any wire assertion in this chunk must read the family, not a bare name.
- **a11y ↔ tests:** the `Report.tsx` CARRY fix runs through the CI **A11y suite** stage `cargo xtask test:a11y` (`verify:contrast` → Playwright/axe → Lighthouse → pa11y → aggregator → regression-detector) plus vitest; the contrast threshold is a11y's, the harness wiring is test-plan §9 Pipeline structure.
- **security ↔ tests:** the "bounded fields, never the payload" ban gets its test form from test-plan §1's AppError-sanitization trigger shape (grep the log, assert metadata-only).
- **arch ↔ tests:** if the frontend arm wins, the `EXPECTED_PROCEDURES` pin + regenerated `pulse-app/ui/src/bindings/index.ts` must be **STAGED**, asserted by `cargo xtask check:staged-artifacts` (also folded into `capability-drift`) per test-plan §3 + §9 Staged-artifacts row.
