## Relevance
Relevant (partial) — perceivable (contrast, decorative-icon) + the delegated ARIA-role decision + harness coverage apply; focus/keyboard/forms/motion do not (no interactive control, no form, no animation named).

## Constraints
- **Tier & evidence:** Standard → **WCAG 2.1 AA**; every SC needs a machine-verifiable path and semantic-HTML-first (no ARIA on non-semantic markup) — the empty panel is plain semantic text/markup, verified by the axe sweep, not manual-only (per a11y-plan §1, §2).
- **Contrast (load-bearing):** the muted message must meet **SC 1.4.3 4.5:1** against `--color-base` at its rendered `--font-body` size. `--color-text-tertiary` is documented at 3:1 (large-text only) and was a repeat body-size failure remediated tertiary→secondary in chunk #99 — a tertiary/`-muted` token at body size will fail the gate (per a11y-plan §6 contrast pairs + §11 Visual).
- **Decorative glyph:** the Observatory glyph carries no unique meaning (the text does), so it must be `aria-hidden="true"` / empty-alt and the "what to do" must live in text, not glyph or color alone — **SC 1.1.1 / SC 1.4.1** (per a11y-plan §6 not-color-alone, §7/§11 Screen Reader).
- **ARIA-role decision (delegated from scope open-Q3):** use **plain semantic text — NOT `role="status"`/`aria-live`**. The panel is persistent route content read in normal order on navigation, not a non-blocking status *update*; live regions are reserved for update/progress/alert events (per a11y-plan §7 live-regions, §4 Status/Alert). Keeping it non-live also prevents a mistimed announcement given the "must not flash during initial fetch" rule.
- **No interactive control (affordance-EXEMPT):** introduce no new focus stop or tab order — keep the actionable hint as text, with no `tabindex`, no fake button/link, no `role` on static markup (per a11y-plan §5, §11 Keyboard/ARIA).
- **Harness/SLO:** the empty branch renders on the Metrics/Logs full-dashboard layouts (P1/P4 must-be-accessible paths) → **zero new WCAG AA violations**; it must be audited under axe via a zero-data fixture and the regression baseline must stay at 0 violation tuples (per a11y-plan §3 Harness wiring, §10 SLO).
- **Conditional motion:** if the empty state animates in, apply a `motion-reduce:` degrade-to-instant variant (SC 2.3.3) — otherwise N/A (per a11y-plan §6 Motion, §11 Motion).

## Anti-patterns to avoid
- NEVER render the muted message below the WCAG minimum — no `--color-text-tertiary` on body-size copy (< 4.5:1) (a11y-plan §11 Visual).
- NEVER expose the decorative glyph to SR or convey the next step by icon/color alone — glyph `aria-hidden`, meaning in text (a11y-plan §11 Screen Reader; SC 1.4.1/1.1.1).
- NEVER add a gratuitous live region (`role="status"`/`aria-live`) or a non-operable pseudo-control to a static informational panel (a11y-plan §11 ARIA + Keyboard; §2 semantic-HTML-first).
