## Patterns to follow
- Explicit instant parameter as the clock (test-plan §4 triage crate: "the clock is injected as an explicit `now_nanos` parameter, not via `tokio::time::pause()`"). The rise/fall `tier_effective_at` selection and the ms-duration computation should take their instants as arguments so both cases can be pinned as pure functions.
- Allowlist-leaf boundary pins in `pulse-app/tests/unit_observability_allowlist_*.rs`. The existing `unit_observability_allowlist_delegated_timing.rs` is the carrier to extend when the named duration field is admitted to `metric.constellation.hue_update_ms` (or to a sibling leaf) (test-plan §2 pulse-app exception; §1 triggers `cadence-cycle-rate-in-crate-coverage` and `window-navigation-check-behaviour-unit-coverage`, which distinguish an allowlist pin from a behavioural one).
- Measure-first RED/GREEN legs, each on its own fresh data dir (test-plan §3 Direct-binary smoke variant). The HEAD leg witnesses the staleness-anchored, slowest-wins emission. The GREEN leg witnesses per-changed-service emission anchored on `tier_effective_at`. Decide the leg's evidence shape before choosing it.
- A verdict that must prove it ran (test-plan §6 E2E table, `webview-drive` row: "assert the leg RAN … never just its exit code"). The same shape applies to the CI half: acceptance keys on real jobs started (checks > 0 on the sha), not on the absence of a parse error.

## Anti-patterns to avoid
- A one-time live proof standing in for a committed guard (test-plan §1 Pending coverage triggers: the `window-navigation-check-behaviour-unit-coverage` / `ipc-rejection-wire-coverage` / `llamacli-inference-error-emission-coverage` class). An allowlist pin that stays green while the fire site regresses to staleness anchoring or slowest-wins would repeat that class. The behavioural half (duration measured from `tier_effective_at`, one emission per changed service) needs its own committed test that a mutation reddens.
- test-plan §11 Universal / §6 E2E ban visual or pixel inspection as a verdict ("canvas pixel inspection remains out of scope"). Hue correctness is asserted through the emitted record and the payload contract, never by eye. Grading P-025 against the ≤2 s budget is Conductor's live leg and not a CI gate (scope §Boundaries).
- test-plan §11 CI bans a floating-tag action reference and lowering a threshold to pass. The workflow fix must not add unpinned actions or relax any gate to get the first real run green. Scope directive item 2 separately requires real failures that run surfaces to be triaged as findings.
