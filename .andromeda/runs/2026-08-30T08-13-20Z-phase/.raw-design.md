## Constraints

- State must never be conveyed by color alone — the REJECTED state requires a text label or icon alongside the accent (per design-system.md §Color Palette → Accent usage + §Anti-Patterns → Universal Bans "NEVER use color purely for decoration").
- If the IN-FLIGHT copy state (`__mockDelayMs`) animates, §Motion caps chrome at 150 ms ease-out hover/focus and 200 ms fade, bans opacity fades &gt; 200 ms, and requires the app-wide token-bound `prefers-reduced-motion` override (per design-system.md §Motion + §Motion "Accessibility"). Whether the existing state animates at all is research's question.
- B6's `WIDGET_EDGE_MARGIN = 24` must trace to the scale — 24 px is `space-lg`, a multiple of the 4 px base unit (per design-system.md §Spacing). A geometry assertion that hardcodes `24` as a bare magic number rather than naming the token step is the shape §Self-Validation Protocol #4 (Token Test) rejects; the constant is Rust-side, so this is a trace/annotation requirement, not a CSS one.
- D2's disproved claim is duplicated inside design's own plan: `.andromeda/design-system.md:216` (§Surface: desktop-webview → Toolkit / Framework) and `:391` (§Anti-Patterns → Per-Surface Bans, desktop-webview) both name "shadcn/ui (Radix UI primitives)" as the component stack — the same lockfile-absent, `npm-policy.json`-denylisted library D2 corrects at layout-templates :17/:145. - Anything the new specs render or assert on must reference design tokens only, no hardcoded hex or px literals (per design-system.md §Self-Validation Protocol #4 Token Test).
