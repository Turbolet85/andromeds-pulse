## Relevance
Partial — adds a rendered plain-language status-line (text) plus an accessible-name fix to the existing `ConnectionDot` on the full-dashboard (a must-be-accessible path, P1/P4); the Perceivable (contrast SC 1.4.3, not-color-alone SC 1.4.1), Status-Message (SC 4.1.3), and text-alternative (SC 4.1.2/1.1.1 on the `role="img"` dot) slices are in-domain. Keyboard/focus/forms/motion/target-size do not apply (non-interactive text, no new keybindings, no animation, no form input).

## Constraints
- Standard tier → **WCAG 2.1 AA** is the target for any new webview surface; the status line renders on desktop-webview so AA applies (per a11y-plan §1 WCAG Criteria Mapping). Rendered text is **not** "contrast-exempt" — the scope's tentative exemption is a scaffolding point (no new spec/keyboard test), not a waiver of the text-contrast sweep.
- Text contrast SC 1.4.3: status-line body text must use `--color-text-primary / --color-base` ≥ 4.5:1 (only `--color-text-secondary` at ≥3:1 if rendered as large text); do **not** use `--color-text-tertiary` for small text (per a11y-plan §6 Color contrast pairs).
- Not-color-alone SC 1.4.1: if the line/dot uses state color (`--color-feedback-success` connected / `--color-accent` no-telemetry), meaning must also be carried by the words — this chunk *is* the not-color-alone complement to the dot (per a11y-plan §6 State color tokens + §1 visual-discrimination trigger).
- Status messages SC 4.1.3: since the line live-updates (source count / spans-per-second / buffer fill), expose it as a non-blocking `status` / `aria-live="polite"` region that never moves `document.activeElement`; do **not** announce every per-second tick — reserve polite announcements for the connected↔no-telemetry transition to avoid SR spam (per a11y-plan §7 Live regions + §1 P4 "announces without interrupting" + §11 SR excessive-ARIA-noise ban).
- ConnectionDot text alternative (CARRY): the dot is a non-interactive `role="img"` with an `aria-hidden` decorative tooltip, so the honest-recency fix must correct the dot's **accessible name** (aria-label on the role="img"), not just the aria-hidden visual tooltip — SR reads the name (SC 4.1.2 / 1.1.1); keep the SC 1.4.13 non-applicability intact (per a11y-plan §1 SC-1.4.13 line).
- Semantic HTML first + machine-verifiable evidence: render as real text in semantic elements, ARIA only where HTML is insufficient; any AA claim needs axe/Lighthouse/pa11y JSON, not manual-only (per a11y-plan §2 agent-runnable invariants).

## Patterns to follow
- Status/Alert live-region pattern — `status` role + `aria-live="polite"`, no focus-steal, mirroring the P4 throughput/error-rate counter precedent (per a11y-plan §4 Status/Alert row + §7 Live regions + §1 P4).
- Contrast token discipline — reuse `--color-text-primary / --color-base`; follow the chunk-#99 remediation precedent that migrated small-text tables off `--color-text-tertiary` to hit 4.5:1 (per a11y-plan §6 + 2026-06-10 amendment).
- ConnectionDot `role="img"` summary — state exposed as an accessible name on a non-interactive `role="img"` with a decorative aria-hidden tooltip; mirror this when writing honest recency into the name (per a11y-plan §1 SC-1.4.13 line).
- Adding-a-surface convention — a new component on an **existing** route folds into that route's existing axe spec (full-dashboard/p1) rather than needing its own; update `helpers/v02-fixtures.ts` to render both live and zero-telemetry states so axe/pa11y actually sweep the line (per a11y-plan §3 Harness wiring & conventions).

## Anti-patterns to avoid
- NEVER convey connection/no-telemetry state by color alone — pair every state color with text (per a11y-plan §11 Visual / SC 1.4.1); do not regress the very gap this chunk closes.
- NEVER use a foreground/background pair below 4.5:1 (or 3:1 large text) for the line's text — the colorjs.io + axe-core gate enforces per token pair; a hard gate, not exempt (per a11y-plan §11 Visual + §10).
- NEVER leave essential content only in the `aria-hidden` tooltip — the honest recency must live in the accessible name (per a11y-plan §11 Screen Reader, aria-hidden-on-essential-content ban).
