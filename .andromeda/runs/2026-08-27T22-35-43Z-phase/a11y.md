## Patterns to follow
- Fixture/mocking pattern: TauRPC procedures are invoked as `TauRPC__<router.path>`; incident fixtures live in `pulse-app/ui/tests-a11y/helpers/v02-fixtures.ts` and **must be POPULATED** (an empty array renders nothing and the sweep passes by comparing nothing) (per a11y-plan §3 Harness wiring & conventions).
- Cheap suite-health check before trusting a green a11y run: `npx playwright test --list` — a list-time import failure once silently disabled the whole suite (per a11y-plan §3 Harness wiring & conventions).
- Machine-verifiable evidence discipline: any claim that a11y is unaffected must rest on harness JSON output (axe-core / Lighthouse / pa11y / focus-order JSONL), never on inspection (per a11y-plan §2 Agent-runnable invariants + §11 Strategy).
- Violation reporting shape if anything does trip: structured violation JSON with `wcag_criterion` / `violation_type` / `severity` / `surface` / `selector` / `remediation` / `tool` / `tool_result_id`, aligned to the obs log format (per a11y-plan §3 Structured violation JSON schema).

## Anti-patterns to avoid
- NEVER skip a11y on CI failure or defer it to a follow-up — it is a fail-fast merge gate, not a warning (per a11y-plan §11 CI).
- NEVER apply a retry-once policy to an a11y test that flakes while backend timing changes; quarantine and investigate instead (per a11y-plan §11 SLO).

## Contract bindings
- **a11y ↔ tests:** the a11y chain runs in the same `ci.yml` pipeline and reuses tests' 5-command E2E driver (`boot` / `run` / `status` / `cleanup` / `logs`); a change to the RED-arm harness or CI job wiring must keep that step intact (per a11y-plan §3 CI integration + §9).
- **a11y ↔ obs:** a11y violation JSON is emitted in obs's structured log format with the obs Section 3 resource attributes (`service.name` = `"com.andromeda.pulse"`, `deployment.environment`) for cross-correlation (per a11y-plan §3 Structured violation JSON schema + §9).
- **a11y harness ↔ UI bindings:** `pulse-app/ui/tests-a11y/helpers/v02-fixtures.ts` consumes the generated binding types (`pulse-app/ui/src/bindings/index.ts`) for `IncidentRecord` / `incidents.list_active`; if the remedy regenerates bindings, the fixture must follow in the same chunk (per a11y-plan §3 Harness wiring & conventions).
