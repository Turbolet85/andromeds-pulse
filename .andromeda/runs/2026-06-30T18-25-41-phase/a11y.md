## Relevance
Partial — suppresses browser affordances in production; must preserve keyboard/focus per critical paths P1–P7 (Settings form Tab navigation, modal Escape close, canvas interaction).

## Constraints
1. **§1 P7 + §5 Keyboard Navigation:** Settings form requires Tab cycling through form controls and Esc to close modal; context menu suppression must not interfere with focus management or keyboard trap escape.
2. **§6 Focus Management:** Canvas drag suppression must not disrupt Tab/arrow key navigation through traces, metrics, logs; focus order stable per §1 P1–P4.
3. **§5 Keyboard Navigation:** Escape key works from any modal (settings, investigation); context menu handler must not consume Escape before modal handlers fire.
4. **§1 P7 + §4 ARIA Patterns:** Form controls (inputs, radio, switch in Settings) require native copy/paste; context menu suppression must exempt editable fields to preserve text selection (SC 3.3.2, SC 4.1.2).
5. **§1 SC 2.1.2 No Keyboard Trap:** All surfaces (dashboard, widget, modals) require keyboard-only navigation; suppression must not introduce unexpected focus theft or Escape consumption.
6. **§3 Harness Contract:** Verification method is webview (vitest DOM test dispatching real `contextmenu` events); must assert suppression in PROD mode only (dev Inspect preserved per §import.meta.env.PROD).

## Patterns to follow
1. **Production-gating via import.meta.env.PROD** (per scope §Production gate) ensures dev-build right-click → Inspect/devtools preserved; production-only suppression protects against unintended accessibility impact.
2. **From a11y-plan §3 Harness Contract:** Leverage existing Playwright E2E + axe-core vitest infrastructure; no new tooling required for verification.
3. **Selective exemption pattern (P4 scope-ambiguity):** Consider exempting form field inputs from context menu suppression to preserve native copy/paste/select-all affordances (per scope "Whether to EXEMPT editable elements...").

## Anti-patterns to avoid
1. Do not suppress context menu in a way that breaks copy/paste or native text selection in form fields (violates SC 3.3.2, SC 4.1.2).
2. Do not consume Escape key before modal exit handlers (violates SC 2.1.2 No Keyboard Trap; modals at P2, P3, P7 all require Escape-close).
3. Do not remove canvas elements from Tab/arrow-key navigation by suppressing drag affordance (violates SC 2.1.1 Keyboard, SC 2.4.3 Focus Order for P1–P4 interactive traces/metrics).
