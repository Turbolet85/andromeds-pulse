## Anti-patterns к avoid

- NEVER convey backoff cool-down state by color alone (e.g., grey-out button as the only signal) — pair с text countdown OR icon label per a11y-plan §11 Visual anti-pattern row 1 + WCAG SC 1.4.1.
- NEVER move focus away from the trigger button automatically when the retry completes — steals focus from а keyboard user mid-task; a11y-plan §11 Keyboard discipline + Critical Path P4 "Live updates do NOT steal focus" + SC 2.4.3 Focus Order require focus stability across async updates.
- NEVER use `aria-live="assertive"` for routine retry-success messages — reserve assertive/alert for truly interrupting state per a11y-plan §7 Live regions row 2; routine success uses `polite`.
- NEVER add `role="button"` к а non-`<button>` wrapping element — semantic HTML first per a11y-plan §11 ARIA anti-pattern row 1 + eslint-plugin-jsx-a11y compile-time gate.
