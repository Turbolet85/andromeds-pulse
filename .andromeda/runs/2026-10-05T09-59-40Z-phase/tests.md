- Real-model generations are never a gate, per test-plan §1 Pending coverage triggers → `l4-decision-probe-arg-parse-unit-coverage`: "a real-model generation cannot give a deterministic verdict". ## Patterns to follow
- Drive flag parsing through the existing `parse_args_from(iter)` seam, and drive per-row readings through pure fns, per test-plan §1 `l4-decision-probe-arg-parse-unit-coverage`. That row records how `--shapes` / `--sampling` / `--gbnf` / `--footprint` and the `thinking` / `elapsed_ms` / `peak_*` readings were pinned.
- Mutation-check each new pin: neutralise the branch and confirm the pin reddens. This is the practice recorded throughout test-plan §1 (e.g. `--shapes` "widening the default reds the first") and §4 triage ("mutation-checked").
- Write asymmetric pairs for each scorer label, per test-plan §4 triage. That section notes that "omits" pins "guard only as the negative half of their pair". Pin B-control "not surface" readings together with A/C "surface" readings, and pin cause-hit together with a cause-miss (wrong service, or no cause word) on the same shape.
- A verdict proves its own preconditions, and an unmet precondition reads INCONCLUSIVE, never PASS, per test-plan §3 Per-chunk gate discipline (the `smoke:*` scenario legs' 0/1/2 exit contract). The probe already owes an INCONCLUSIVE exit 2 on an unset or guard-rejected L4 path (§1 row, still owed). The series should carry the same discipline for a model that produced no reading.
- Build synthetic digests at runtime through the product renderer, never from pre-baked fixtures, per test-plan §7 Self-bootstrapping requirement and §2 "Self-bootstrapping fixtures". Whether `render_payload` can express each A/B/C shape (no cue, A7's wrong-service cue, A6 corpus matches) is research's question, per the scope's P3 premises.

## Anti-patterns to avoid
- Do not let a zero-generation row pass vacuously. Test-plan §3 Direct-binary smoke variant (the BLOCK-shaped rule) records that an absent output emits nothing and makes a clean-reading assertion pass "VACUOUSLY". In this chunk, `thinking absent` plus a fast `elapsed_ms` on an empty generation must be labelled `no reading`. It must never be `valid`, and never a correct B dismissal (scope CARRY 1).
- Do not commit synthetic digest text or raw model output, per test-plan §11 Universal ("NEVER expose secrets in test output") and §11 Test Data. Keep them in gitignored `target/`, and keep committed evidence to labels and aggregates.
- Do not read real time inside a pinned function, per test-plan §11 Universal ("NEVER use real time … without injection"). Pins over latency or time-budget classification (the `valid` "inside the time budget" atom) take the elapsed value as a parameter.
