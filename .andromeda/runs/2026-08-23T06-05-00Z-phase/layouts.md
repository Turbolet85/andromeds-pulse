## Constraints
- The Traces hero renders **one dot per service** from the `traces.query` result, with always-on per-dot name + severity-token labels, in the fixed (`flex-shrink:0`) region above the table (per layout-templates.md §Wireframe — Full dashboard (Traces primary screen) + §Component — Halo State Pulse canvas). Any per-class treatment that rewrites `spans.service_name` renders **directly as the visible dot label**, and a false positive that forks one identity renders as two dots. Whether the dot list is derived from the scrubbed column or from a pre-scrub path is research's question.
- The shipped desktop-webview signature is the **constellation dot hue** keyed to cumulative incident severity per service (`severityToHueFraction` → `ConstellationDot.priorityTier`); the WebGPU halo layer is recorded SPECIFIED-BUT-UNBUILT and its build-or-retire is owned by a separate working-route entry (per layout-templates.md §Component — Halo State Pulse canvas, MEASURED 2026-08-21 note). A forked service identity splits accumulated severity across two dots, degrading the plan-mandated signal — so identity preservation is a requirement of this surface, not just of the SQL.
- The full-dashboard footer is required to carry the plain-language `ConnectionStatusLine` stating **connected-source count ("Receiving from {N} services")**, spans/s and buffer fill, live-updating on a 1 s poll with the count gated by P-067 recency (per layout-templates.md §Component — Footer (read-only status bar) → Full dashboard). N is a distinct-service count, so over-redaction that forks or collapses service identity changes a user-facing number. Whether that N derives from the scrubbed column is research's question.
- The trace table's **Service column** renders the service name in `font-body` / `color-text-primary`, sits alongside the anomaly-first default order and the `Errors only` `aria-pressed` toolbar toggle, and its headers are click-sortable (per layout-templates.md §Component — Trace data table → Columns / Sorting / Filter toolbar). Any redaction placeholder becomes user-visible text in that column and participates in sort ordering.
- The data views are required to check the **error variant BEFORE the empty variant** so a failure never masquerades as "no data", and to show the empty branch (with the `:4318` / `:4317` exporter hint) only on a *settled* zero-data load (per layout-templates.md §Component — Empty / error state). If the chosen treatment is the scope's drop-and-count candidate, a view that goes zero-row must not present as "nothing received yet".
- This chunk introduces no window, region, component placement, focusable element, modal or responsive behavior, so §Responsive behavior and §Keyboard shortcuts impose nothing new; and layout-templates.md is frozen mid-run ("Do not edit during implementation runs", per layout-templates.md top-of-file scope note), so any *surfaced* redaction affordance would be a wrap-time amendment, not an implicit addition.

## Patterns to follow
- **Aggregate-glance widget vs. worded dashboard**: the compact widget footer is `Ingest / Error / Retention` only and carries no worded line; worded status is dashboard-only (per layout-templates.md §Wireframe — Compact widget + §Component — Footer). If any redaction count is ever displayed, the dashboard footer read-only band is its only sanctioned home.
- **Fixed hero + bounded route (P-082)**: the Traces route is bounded to the shell's `main` height with `overflow:hidden`; hero + toolbar stay fixed and only the table's own region scrolls with a sticky opaque `color-base` thead (per layout-templates.md §Wireframe — Full dashboard (Traces primary screen) + §Component — Trace data table → Internal scroll region). Row/label population changes must not grow an outer page scrollbar.
- **One shared `EmptyState` across Metrics / Logs / Snapshots** so the data views read as one system (per layout-templates.md §Component — Empty / error state) — no per-view bespoke zero-data messaging if a treatment changes what lands.
- **Sketch-lag handoff discipline (P-070 / P-082)**: the Traces ASCII wireframe's footer row and per-dot label detail are known-illustrative-lag, corrected only by a future *targeted* touch-up — never opportunistically inside an unrelated chunk (per layout-templates.md §Wireframe notes, Traces).

## Anti-patterns to avoid
- Never surface backend internals in a data view: the error variant is a static message ("Couldn't load {metrics|logs}") with **no** raw `AppError` and **no** exporter hint (per layout-templates.md §Component — Empty / error state → Error).
- Do not add a redaction/PII indicator or control to the compact widget — it stays minimalist always-on-top glance chrome with settings-gear-only navigation (per layout-templates.md §IA notes → Navigation model + §Wireframe — Compact widget).
- Do not touch the Halo State Pulse canvas section or its build-or-retire question; it is owned by a separate working-route entry (per layout-templates.md §Component — Halo State Pulse canvas).
