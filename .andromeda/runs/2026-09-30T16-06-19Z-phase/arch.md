Re-pointing the snapshot arm at a whole-generation sample, or giving the empty-frame line a named cause, changes that registered contract text — the exit-code set and the nearest-rank rule stay as they are (the scope's boundaries also keep both). The registry entry is amended at wrap.
- The currently registered empty-frame line is the fixed string `frame: cannot-evaluate: 0 samples, no WebGPU adapter in this run` (arch §Occupied Resources → xtask CLI surfaces). It asserts a cause it cannot know. The chunk's closed cause vocabulary replaces it, and it must remain a cannot-evaluate/not-required outcome: never a PASS, and not a new exit code.
- A new webview→backend record needs three things per arch §Cross-cutting Patterns → Webview IPC capability policy: router registration in the owning crate, an Occupied Resources entry, and its `EXPECTED_PROCEDURES` pin, staged together with the regenerated bindings so the staged `capability-drift` assertion stays clean. It needs NO capability-JSON edit. Naming is `<router>.<verb>` snake_case per arch §Conventions → Endpoint naming. The natural home is the `telemetry.frontend.*` family in `crates/ui-bridge/src/telemetry.rs` (arch §Occupied Resources → Tauri IPC routes). Reusing an existing procedure vs adding one is research's question.
- A bridge argument must be a validated `serde` struct with a closed enum / bounded label, per arch §Established Decisions → [Validation Library] and §Inherited Defaults → Validation. It returns `Result<T, AppError>` with the stable variants in arch §Conventions → Error response schema (Tauri IPC), and it must be `serde::Serialize` across the bridge (arch §Cross-cutting Patterns → Cross-bridge data shape).
- Module dependency direction per arch §Cross-cutting Patterns → Module dependency direction and §Inherited Defaults → Module boundaries: dependencies flow toward `pulse-app` and siblings do not depend on each other unless their contract requires it. Arch registers `snapshot.generate` as implemented at `pulse-app/src/snapshot_runtime.rs` (arch §Occupied Resources → Tauri IPC routes). A whole-generation timer that spans load + curate + format must therefore sit where that orchestration lives, without adding a `snapshot` → sibling edge. Research decides where the stages are actually orchestrated.

## Patterns to follow
- The delegated-timing / webview-observable route: a fact visible only in the webview (here, the `requestAdapter()` result) reaches the log only through a `telemetry.frontend.*` procedure. Each procedure has its own bounded input struct, its own self-observation target, and its own exact obs allowlist leaf. There is no bare-namespace fallback, and a leaf-less target silently redacts its labels. See arch §Occupied Resources → Tauri IPC routes, entries `telemetry.frontend.record_constellation_*` and `record_ipc_rejection`.
- The `IpcRejectionInput` shape (closed serde enum + coerced bounded label + validated bounded number, never rejecting) is the precedent for a closed adapter-cause input (arch §Occupied Resources → Tauri IPC routes → `telemetry.frontend.record_ipc_rejection`).
- A formalized xtask CLI contract: named verdict arms, stable exit codes, and a one-line-per-arm stdout. Contract changes are registered in §Occupied Resources per the 2026-08-25 formalized-CLI-contract rule (arch §Occupied Resources → xtask CLI surfaces).
- Shared CI logic that needs Rust lives in `xtask` so the gate runs identically locally (arch §Infrastructure Patterns → CI/CD approach; §Cross-cutting Patterns → Development Style: machine-parseable, schema-stable outputs).

## Anti-patterns to avoid
- Adding a TauRPC procedure without its `EXPECTED_PROCEDURES` pin and staged bindings, or "legitimizing" it with a per-procedure capability-JSON entry. Neither is the gate in this project (arch §Cross-cutting Patterns → Webview IPC capability policy).
- Carrying raw adapter strings (vendor / architecture / description text) across the bridge as an unbounded label, or serializing internal error detail into `AppError::Internal` (arch §Conventions → Error response schema (Tauri IPC)).
- Pointing any self-observation at the product's own `:4317`/`:4318` to carry the adapter record or the snapshot sample (arch §Cross-cutting Patterns → Self-observation discipline).

Retargeting the grader (arch §Occupied Resources → `perf:budget`) must match the obs-plan target and its allowlist leaf. A new adapter-record target needs its own exact allowlist leaf (arch §Occupied Resources → `telemetry.frontend.*` note on leaf-less `metric.*` redaction).

- arch ↔ CI/infra: the `release-{os}` cache key and the 10 GB cap figure (arch §Infrastructure Patterns → CI/CD approach) are re-measured by `gh api …/actions/cache/usage`.
