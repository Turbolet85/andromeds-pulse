- NEVER add any OTel SDK crate (`opentelemetry`, `opentelemetry_sdk`, `opentelemetry-otlp`, `opentelemetry-stdout`) to workspace `[dependencies]` for self-observation — recursion-free-by-construction is the architectural invariant; only `tonic` / `axum` / `prost` / `opentelemetry-proto` (wire-format-only) are permitted, and only in `ingest` for external OTLP decoding (per obs plan §11 Universal anti-pattern row 4; §12 Decisions Log 2026-05-02 user review pivot).
