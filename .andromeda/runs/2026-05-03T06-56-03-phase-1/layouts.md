## Patterns к follow

- Custom frameless titlebar shared between compact widget and full dashboard: `[app-icon + title | grow | settings-button | window-controls]` flex layout with `data-tauri-drag-region` on the container — establish window configuration that supports this in chunk 2's `tauri.conf.json` (per layout-templates.md §desktop-webview Component — Custom titlebar).
- Three-surface coherence pattern: compact widget (glance), full dashboard (exploration), tray icon (ambient status) all share the same TauRPC data feed via broadcast channels — chunk 2's capability JSON should not artificially partition these three surfaces from the shared `traces.*` / `metrics.*` / `logs.*` IPC surface (per layout-templates.md §desktop-webview IA notes Multi-surface coordination + §desktop-native IA notes Cross-surface coordination).
- Platform-native tray adapter pattern: tray icon uses `NSStatusItem` (macOS), `NotifyIcon` (Windows), `AppIndicator`/`StatusNotifier` (Linux); chunk 2's Tauri scaffold should leave platform-specific tray protocol selection to Tauri 2 abstractions rather than locking to a single-platform impl (per layout-templates.md §desktop-native Platform-specific notes).

## Anti-patterns к avoid

- Do NOT scaffold a single fixed Tauri window definition that conflates compact widget + full dashboard semantics — they have distinct sizing (fixed quarter-screen vs. resizable), distinct always-on-top behavior, and distinct chrome (per layout-templates.md §desktop-webview Primary screens).
- Do NOT enable Tauri's default OS-chrome titlebar in chunk 2's `tauri.conf.json` — both webview surfaces use a custom frameless titlebar; defaulting to OS chrome forces a future migration that regresses the drag region + signature-element placement (per layout-templates.md §desktop-webview Component — Custom titlebar).
- Do NOT scaffold a tray capability that forbids secondary always-on-top click-through windows — the WebGPU Halo Pulse overlay around the tray glyph requires a secondary composited surface (per layout-templates.md §desktop-native Component — Tray icon Option A WebGPU).
