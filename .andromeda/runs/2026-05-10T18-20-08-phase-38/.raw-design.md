## Patterns to follow

- Hierarchical container layering: H1 ↔ Base surface (#1A1D24), H2 ↔ Raised-1 panel sections (#262A33), H3 ↔ Raised-2 / Raised-3 nested cards (#2D3139 / #343A45). Carry this elevation model into markdown depth so the visual mental model from compact widget → dashboard → modal maps cleanly to page → section → subsection (per design-system.md §Depth Strategy + §Color Palette Surface Scale).
- Anti-decoration discipline: every section, every truncation marker, every anchor MUST communicate meaning. The §Brand Identity "icons clarify, not decorate" rule from §Iconography (size grid section) extends to markdown — never include section dividers / ornaments / emoji ornaments / "tl;dr" filler that does not advance investigation (per design-system.md §Iconography Rule + §Anti-Patterns Universal Bans "NEVER use color purely for decoration" generalized to markdown chrome).
- Observation-log framing language: when introducing anomaly subsections, follow the §Decisions Log "Snapshot generation (curated observation log)" voice — "transient telemetry materializes as persistent narrative" — section labels prefer "Anomaly observations" / "Critical path" / "Service constellation summary" over "Errors" / "Critical span IDs" / "Service breakdown" (per design-system.md §Design Decisions Log 2026-05-02 "Snapshot generation (curated observation log)").
- Truncation indicator copy: when a section is truncated to fit the budget, the marker line MUST itself follow the contemplative voice — e.g., "_(N additional spans elided to honor 25k token budget; anomaly-priority preserved)_" rather than "..." or "TRUNCATED" (per design-system.md §Brand Identity Design direction "color-coded states encode meaning without ornament" generalized to text-state markers).

## Anti-patterns to avoid

- NEVER include emoji-decorated section headings, banner ASCII art, or "delightful" copy ("Here's what we found!" / "Great news!"). The §Anti-Patterns Universal Bans "Bright, contrasty" + Rejected Defaults "delightful framing" bans extend to markdown copy — markdown is brand-bearing chrome (per design-system.md §Anti-Patterns Universal Bans + §Anti-Patterns Rejected Defaults "Animated state transitions ... delightful").
- NEVER use "exported data" / "report" / "dump" framing in heading text — the artifact is a curated observation log (per Decisions Log 2026-05-02), not a database export. The §Surface: desktop-native Tray Menu pattern bans "Generate Snapshot, not Export Data; Toggle MCP Server, not Enable AI Integration" — same discipline applies to anchors and section titles inside the markdown body (per design-system.md §Surface: desktop-native Tray Menu Tone).
- NEVER drop anomaly evidence to fit budget BEFORE dropping low-signal verbose attributes / aggregated p50 detail. Halo signature semantics (Alert Burgundy + faster pulse hue+rhythm encoding "broken + busy") demand anomalies survive every truncation tier; chunk #40's already-filtered attribute set (kept_attributes from allowlist) and aggregated percentiles drop FIRST (per design-system.md §Brand Identity Signature element + §Anti-Patterns Rejected Defaults "Uniform monochrome status icons" rejection rationale).
