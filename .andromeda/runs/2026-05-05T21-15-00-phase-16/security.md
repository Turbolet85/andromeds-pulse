## Anti-patterns to avoid

- NEVER use `tower_governor` defaults that include any client-IP-based keying that would log raw remote-address headers — coarse-global + source-port keying only; raw IP / hostname strings are forbidden in logs per security plan §Logging NEVER-log list "internal hostnames or IPs in OTLP error responses or MCP error objects".

- NEVER allow rate-limit middleware error responses to leak Rust struct names, library versions, or stack traces — `From<GovernorError> for Response` must collapse to sanitized `tonic::Status` / `Status` proto only (per security plan §Security Anti-Patterns § Logging row 4 + §Error Handling External responses).
