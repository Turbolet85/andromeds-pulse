## Constraints

- The export trigger lives in the existing Settings surface; reuse the **Button (secondary)** pattern — `bg-raised-1` (#262A33), text `--color-text-primary` (#E8EEF7), 1px subtle border `rgba(74,144,226,0.3)`, hovered border `#4A90E2`, `radius-sm` (4px), padding `space-sm` horizontal + `space-xs` vertical. Export is a deliberate action, not a primary CTA like "Investigate" — do NOT use the Primary `#4A90E2`-fill button (per design-system §Surface desktop-webview > Component Patterns > Buttons).
- The preview dialog MUST use the **Modal elevation** pattern: `--color-raised-3` (#343A45) background + 1px border (subtle or emphasis), positioned via z-index only, NO shadow (borders-only depth strategy). Radius `radius-lg` (8px) for the largest-surface container, padding `space-md` (16px) (per design-system §Depth Strategy + §Border Radius + §Surface desktop-webview Modal note).
- The preview summary's numeric values (record counts by category, date range) MUST render in `--font-code` (JetBrains Mono) 12px with `tabular-nums` — these are telemetry/count data, "immutable fact" per the monospace-vs-sans semantic split. Labels and the anonymization-confirmation prose use `--font-body` (IBM Plex Sans) 14px (per design-system §Typography Data + Body rows).
- Every color in the surface MUST encode meaning, not decoration — the anonymization-confirmation affirmation may use Feedback Cyan (#17B3A3, Success) paired with text/icon; any "no data to export" empty state uses `--color-text-tertiary` (#7D8697); any export-write error uses Alert Burgundy border (#C7556A) + accent-or-primary text + icon (per design-system §Anti-Patterns "NEVER use color purely for decoration" + §Surface desktop-webview Loading/Empty/Error States).
- The export confirmation/preview MUST be a styled shadcn/ui Dialog — NEVER `window.confirm()` / `alert()` / `prompt()` for the destructive-adjacent "are you sure you want to export" gate (per design-system §Per-Surface Bans desktop-webview + §Anti-Patterns; design-tokens.md rule).
- If a system file picker is offered for the target path, use the OS-native dialog (`IFileDialog` / `NSOpenPanel` / zenity) — never a custom in-webview file browser (per design-system §Surface desktop-native > Dialog "File picker for snapshot export: native OS dialog. Never custom file browser"). Note: the default path is `~/Downloads/pulse-corpus-export-{timestamp}.jsonl`, so a picker may be optional.
