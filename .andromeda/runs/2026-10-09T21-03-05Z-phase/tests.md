## Patterns to follow
- A pure decision function pinned per arm, with its probe parsers pinned separately — the form test-plan §3 `status` records for `classify(pid, alive, newest_log)` and test-plan §3 `boot` (Readiness signal) records for `decide_ready`; the native check's host/provisioning verdict (present · missing · cannot-evaluate) fits it.
- Host-independent pins through an injected seam over real `tempfile::TempDir` fixtures, so no pin reads the dev host's own package manager, PATH or `/usr` — the form test-plan §4 Unit Test Strategy (What unit tests cover → interpretation crate, the root-taking CUDA probe seam) records, with test-plan §8 Mocking & Stubbing Discipline (Filesystem: real temp dir, not mocked).
- A platform-guard pin plus a child-environment pin for a verb that spawns stages — the two unit pins test-plan §3 Per-chunk gate discipline records for `perf:frame-sample` (`platform_guard`, `child_env`); the same section's three-arm exit contract (0 / 1 / 2, the third never read as a pass) is the shape every sibling verb there carries.
- A verb proves its own preconditions and reports the non-verdict arm rather than a pass — test-plan §3 Per-chunk gate discipline (the scenario legs' INCONCLUSIVE rule); for this chunk: a stage that did not run, or ran against a missing tool, is never counted green.
- Mutation-check each new branch so its pin discriminates, and treat an "omits"/negative pin as only the negative half of a pair — test-plan §4 Unit Test Strategy (What unit tests cover → triage crate; security crate).

## Anti-patterns to avoid
- NEVER a manual smoke step standing in for an automated one — test-plan §11 Test Anti-Patterns (Universal); the hand-run of the six stages is exactly what the chunk replaces, so no acceptance may rest on it.
- NEVER `std::env::set_var` mid-test without cleanup, and NEVER real time without injection — test-plan §11 Test Anti-Patterns (Mocking; Universal); a test of the stage environment or of the recorded timing/load takes its inputs as parameters.
- NEVER a retry, a `--test-threads=1`, or a skip read as a pass to obtain green — test-plan §11 Test Anti-Patterns (CI; Quality) with test-plan §10 Quality Gates & Coverage Targets (Zero-flakiness budget); a stage that flakes under another builder's load is a finding, not a re-run.
