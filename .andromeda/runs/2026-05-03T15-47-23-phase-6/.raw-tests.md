- Tick-event log lines MUST be agent-parseable as JSON via `jq` against the harness `logs` command output — agent assertion shape: `jq 'select(.target == "buffer.tick") | .fields' logs/*.log` returns ≥1 entry within the test window (per test-plan §3 Log format Agent-parseable signals + §11 Universal "machine-parseable output").
- Heartbeat tests MUST be deterministic with zero retry budget; one flake = immediate quarantine + root-cause investigation (per test-plan §10 Zero-flakiness budget + §11 Quality "NEVER add retry-once policies"). Timer-driven tests are the highest-flake-risk class; pause-and-advance discipline is the mitigation.

## Anti-patterns к avoid

- NEVER use `std::time::Instant::now()` / `chrono::Utc::now()` / wall-clock `tokio::time::sleep` in heartbeat tests — non-deterministic, masks real bugs as flakes (per test-plan §11 Universal "NEVER use real time").
- NEVER assert on tick wall-clock cadence (e.g., "at least 4 ticks observed in 60 real seconds") — assert on advance-driven invariants instead (e.g., "after `advance(Duration::from_secs(15))`, exactly one tick event emitted") (per test-plan §11 E2E "NEVER use `sleep(N)` for synchronization").
- NEVER share mutable state across parallel heartbeat tests (shared subscriber state, shared timer queue) — each test gets isolated tokio runtime + paused clock + ephemeral subscriber registry (per test-plan §11 Test Data "NEVER share mutable state across parallel tests").
- NEVER mock `tokio::time::interval` itself — use the built-in `pause()` / `advance()` API; mocking tokio internals fights the runtime (per test-plan §11 Mocking "NEVER use `mockall` for external libraries").
