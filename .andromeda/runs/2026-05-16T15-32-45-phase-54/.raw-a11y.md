## No domain coverage

Chunk #58 is entirely out of the a11y domain.

**Rationale:** The a11y specialist plan (`.andromeda/a11y-plan.md`) governs accessibility requirements for the webview UI surfaces: WCAG 2.1 AA compliance, ARIA semantics, focus management, keyboard navigation, motion tokens, color contrast, and screen reader compatibility. All a11y concerns are tied to visual/interactive components rendered in the webview.

Chunk #58 performs a backend Rust refactoring operation only:
- Creates `crates/curation/` as a new Cargo library crate
- Moves `dedupe`, `anomaly`, `critical_path`, `aggregation` modules from `crates/snapshot/src/` to `crates/curation/src/`
- Adds `curation::contract` re-export module
- `snapshot` crate's external surface remains unchanged (no new TauRPC procedures, no new IPC events, no new capability JSON entries)

No webview source files, no React components, no CSS/Tailwind tokens, no ARIA attributes, no focus traps, no motion primitives, and no accessibility harness configurations (axe-core, pa11y, Lighthouse, Playwright a11y fixtures) are touched by this chunk.

The a11y plan §3 Bootstrap phases and §Acceptance criteria sections have no applicable triggers for a refactor-only Cargo crate extraction with no UI surface changes.
