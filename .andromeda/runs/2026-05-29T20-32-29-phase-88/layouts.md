The dot hover tooltip (service name + activity rate + lifecycle state) follows this hover-reveals-detail convention; for richer detail the surface convention routes к a modal rather than in-canvas inline expansion (per layout-templates.md §Component — Trace data table Pagination/virtualization note + §Component — Investigation modal trigger).
