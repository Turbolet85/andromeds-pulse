## Patterns to follow
- The single shared `EmptyState` reused across Metrics / Logs / Snapshots (per design-system.md §Loading / Empty States) — one component means one assertion shape covers the views CARRY #7 navigates to.
- Custom glyphs registered as React components and referenced as `&lt;Icon glyph="telescope" /&gt;` at `&lt;Root&gt;/src/components/icons/` (per design-system.md §Iconography) — glyph identity is the stable semantic handle for the Observatory-glyph check, preferable to matching a bare `&lt;svg&gt;`.
- Telemetry table pattern: data cells JetBrains Mono 12px with tabular numerals, 1px subtle row borders, hovered row background change with NO transition (per design-system.md §Surface: desktop-webview → Component Patterns → Tables) — the Traces-render assertion reads rows in this shape, and the instant hover means no settle wait is warranted there.
- Keyboard/focus pattern: every interactive element Tab-navigable, focus ring 3–4px outset #4A90E2 via `box-shadow`/`outline`, `:focus-visible` on all focusables, and hover-only interactions are banned (per design-system.md §Surface: desktop-webview → Focus / Keyboard Navigation; §Anti-Patterns → Per-Surface Bans, desktop-webview) — this is what CARRY #5's "focus survives a refresh" half keys on.
- "Investigate" is a Primary button (#4A90E2 background, #1A1D24 text, radius-sm) whose click is followed by the Investigation Capture Collapse supporting moment at 250–350ms (per design-system.md §Component Patterns → Buttons; §Motion → High-impact moments 2) — the Investigate-result poll bound should clear that window rather than assert immediately after the press.

## Anti-patterns to avoid
- Color alone as state evidence — accent #C7556A is a non-text token (≈3.8:1 on Base), and state must be conveyed with a paired text label or icon (per design-system.md §Color Palette → Accent usage (non-text token); §Anti-Patterns → Universal Bans). An incident/error assertion that reads only a hue passes for the wrong reason.
- Substituting a generic stock-library icon or a generic loading spinner where the Observatory glyph / signature element is mandated (per design-system.md §Anti-Patterns → Rejected Defaults; §Self-Validation Protocol → 1. Swap Test).
- Introducing hardcoded hex or pixel literals, gradients/glassmorphism on chrome, or a banned font into any component touched to expose a selector or test hook (per design-system.md §Anti-Patterns → Universal Bans).

## Acceptance criteria contributions
- (design) The empty-state assertion requires the full mandated composition — Observatory glyph (`aria-hidden`) + message on `--color-text-secondary` + actionable hint naming `:4318` / `:4317` in `font-code` — so the honest-error variant (message, no hint) cannot satisfy it (per design-system.md §Surface: desktop-webview → Component Patterns → Loading / Empty States).
- (design) No stage accepts a color/hue read as sole evidence of state; a severity, error, or incident assertion pairs the color with its text label or icon (per design-system.md §Color Palette → Accent usage (non-text token)).
- (design) Any constellation-side observable targets the shipped dot hue (`severityToHueFraction`), not a Halo canvas layer, and keeps the connection-state grayout axis and the severity-hue axis independently asserted (per design-system.md §Brand Identity → Signature element).
- (design) Assertion waits are bounded past the mandated durations (150ms hover / 200ms fade / 250–350ms Investigate capture collapse) and still hold with `prefers-reduced-motion: reduce`, where those durations collapse to 0ms (per design-system.md §Motion → Accessibility).
