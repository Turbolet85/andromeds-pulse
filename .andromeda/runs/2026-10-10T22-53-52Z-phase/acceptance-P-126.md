Before the door can be reached from another host: on the pull-request run of this chunk's pushed tip, the arm `another_account_is_refused_at_each_of_three_layers` of `pulse-app/tests/integration_door.rs` runs against a spawned `andromeda-pulse-engine`, and (a) a `tools/call` by the engine's owner over `run/door/sock` is answered with content the test sent over OTLP, and (b) a client run as `nobody` and a client run as root under `sudo -n`, with the door's directory and socket opened by the test so that only the door's account check stands, are each refused: the connection is closed with no byte, and after the engine's end its log holds one `door.refused` record with reason `other_account` per client and no `door.call` record from them. The `lint / test` job's step `Door refuses another account` fails unless the arm printed its three-layer sentence, the CI read of that tip is green, and the report names the run id. A run in which the arm skipped proves nothing and fails that step.
