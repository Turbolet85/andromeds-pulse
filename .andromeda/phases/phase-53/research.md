- **Backend producer instrumentation** (`pulse-app/src/streams.rs:53-97`): producer side already emits `tauri.channel.emit` (per-payload INFO) + `tauri.channel.lag` (broadcast lag WARN) — observer side covers the Rust→IPC handoff; the chunk's webview consumer should NOT add its own per-payload `tracing` (obs anti-pattern per combined.md).
- **Halo ref-based prop tracking** (`HaloCanvas.tsx:9-12` comments + general WebGPU pattern): rAF loop reads "latest prop values" via refs without tearing down pipeline. Component re-renders on metrics update; refs sync to latest values; WebGPU loop continues uninterrupted. Real-data subscriptions will trigger re-renders at higher cadence than synthetic 1000ms; ref-based design absorbs this without churn.
- **Vitest mock pattern for TauRPC bindings** (`CompactWidget.test.tsx:7-50`): existing tests already use `vi.mock(...)` for child component stubs (`Titlebar`, `AggregatedBadgeCanvas`, `FooterBand`). The new test pattern can mock either `@/bindings/index` (proxy module) OR mock the new wrapper hook directly (`vi.mock("./hooks/use-widget-metrics")`). Simpler: mock the hook, push fixture WidgetMetrics shapes к component.
