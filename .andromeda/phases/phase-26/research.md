## Patterns detected (existing conventions to follow)

1. **TauRPC trait + impl pattern (per `health.rs` lines 291–339):**
   - Trait declared with `#[taurpc::procedures(export_to = "ui/src/bindings/index.ts")] pub trait XApi { ... }`; methods `async fn name(args) -> Result<T, AppError>`.
   - Impl: `#[derive(Clone)] pub struct XApiImpl { ...constructor fields }; impl XApiImpl { pub fn new(...) -> Self { ... } }`.
   - Public re-export: `#[cfg(feature = "taurpc-runtime")] pub use telemetry::{TelemetryApi, TelemetryApiImpl};` in `crates/ui-bridge/src/lib.rs`.
2. **From-impl + tracing::warn! at boundary (per `contract.rs` lines 155–342):**
   - Each From impl: collapse to sanitized AppError variant + emit `tracing::warn!(target: "ui-bridge.error.{category}", error_category, source_kind, source_crate, ...)`.
   - Test pattern: `app_error_X_round_trips_through_serde` + `from_X_collapses_to_constant_message_no_*_leak` + `from_X_emits_tracing_warn_at_correct_target`.
3. **Co-located test convention:**
   - Rust: `#[cfg(test)] mod tests { ... }` within each `src/` file; no separate `tests/` dir.
   - Webview: `*.test.ts` adjacent to source under `pulse-app/ui/src/`; `vitest.config.mjs` discovers via `include: ["src/**/*.{test,spec}.{ts,tsx}"]`.
4. **WGSL color-uniform discipline (per `design-tokens.md` Session Additions 2026-05-08):**
   - Shader source contains ONLY structural numeric literals (clear color, position output); design-token colors flow as uniforms read from CSSOM at canvas-init via `getComputedStyle(document.documentElement).getPropertyValue('--color-X')`.
   - Verified via `grep -E 'vec[34]<f32>\(0\.[0-9]' pulse-app/ui/src/canvas/shaders/*.wgsl` returning only structural-zero literals.
5. **AllowList per-leaf-entry discipline (per `observability.md` Session Additions 2026-05-07):**
   - Sub-namespaces under existing crate targets (e.g., `ui-bridge.error.{variant}`) need explicit per-leaf entries; `for_target` resolver order is exact-match → strip-suffix `.tick` → `split('.').next()` → `split("::").next()`.
   - Probe via `allowlist_for_target_resolves_X` test pattern before wiring production emission.
6. **Tagged-union fallback (per chunk #28 webgpu-adapter.ts):**
   - `{kind: 'available', ...} | {kind: 'unavailable', reason: <allowlist-discriminator>}` shape; sanitized reason discriminators (allowlist) NOT raw browser error messages.
7. **Reduced-motion gate at frame-loop layer (per `frame-loop.ts` + `CanvasContainer.tsx` line 35):**

## Conventions to follow (project-specific style)

- Rust files `snake_case.rs`; one library crate per module under `crates/<module-name>/`; binary crate is `pulse-app/`.
- Webview source files: per design specialist's convention (kebab-case for `.ts` modules, PascalCase for `.tsx` components).
- TauRPC procedure naming: `<router>.<verb>` dotted-namespace, both segments `snake_case`. For chunk #29: `telemetry.frontend.record_frame_ms` (3-segment is allowed per the existing `IntrospectionApi` + `traces.query` precedent — TauRPC trait method becomes `record_frame_ms` and the trait name `TelemetryApi` becomes the router; the `frontend` middle segment may be implicit via trait naming `TelemetryFrontendApi` or explicit via nested namespace — verify by running `cargo xtask typecheck` after declaration).
- Module visibility: each crate exposes only its public contract via `pub`; cross-crate utilities use `pub(crate)`; no `pub use` re-exports across crate boundaries except in the explicit contract module of each crate.
- Feature flags: `kebab-case`; default features minimal. Chunk #29 introduces NO new feature flag.
- Error handling: all TauRPC procedures return `Result<T, AppError>`; new errors collapse via `From` impl to sanitized AppError variant.
