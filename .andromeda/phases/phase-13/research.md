## Patterns detected

- **Two-tier heartbeat pattern** (`pulse-app/src/heartbeat.rs:51-95` ↔ `crates/ingest/src/contract.rs:9-18` ↔ `crates/ui-bridge/src/health.rs:121-142`): each module crate exports a `{Module}Heartbeat` struct + `heartbeat_payload()` returning current values; pulse-app spawns 15s `tokio::time::interval` per module, calls payload, records timestamp into per-module `HeartbeatState` Mutex slot, emits `tracing::info!(target: "{module}.tick", ...fields..., "heartbeat")`. `current_health()` reads slots back to populate `SubsystemStatus.last_tick_at`. Chunk #16 follows for `ingest.tick`: payload becomes a real read of `IngestState::span_count` etc. instead of `Default::default()`.
- **Default-deny PII allowlist via `FormatEvent` visitor** (`pulse-app/src/observability.rs:99-120` + `.claude/rules/observability.md` Session Additions 2026-05-03 a/b/c): NOT a separate `Layer<S>`; integrated into a custom `FormatEvent` (`JsonWithDefaults`) walking event fields with a redacting `Visit` impl + prepending default identity fields. Per-target lookup via `AllowList::for_target("ingest::grpc")` strips `.tick` suffix → resolves `ingest` key. **Chunk #16 must NOT introduce a separate Layer for ingest-specific redaction; instead extend `AllowList::production()` `ingest` entry OR register matching target keys.**
- **`#[tracing::instrument(skip(req), fields(...))]` discipline for boundaries** (per `.claude/rules/observability.md` "Span discipline"): canonical macro for tonic handlers. `skip(req)` keeps payload out of span; allowlist of `rpc.system = "grpc"`, `rpc.service`, `rpc.method`, `span_count`, `traceparent` fields.
- **Per-module crate template** (`crates/ingest/src/lib.rs` + `crates/buffer/src/lib.rs`): `pub mod contract;` is the only public surface; `contract.rs` exports `Error` (thiserror) + heartbeat payload. **Chunk #16 extends `crates/ingest/src/lib.rs` with new modules (`pub mod grpc;`, `pub mod state;`) keeping the contract module distinct from runtime modules.**
- **Tracing-only self-observation** (`.claude/rules/observability.md` "Self-observation runtime"): `tracing` 0.1 + `tracing-subscriber` 0.3 (JSON formatter) + `tracing-appender` 0.2 + `tracing-error` 0.2. **NO OTel SDK in self-runtime.** External OTLP receivers parse wire format only via `tonic` + `prost` + `opentelemetry-proto`. Chunk #16 MUST NOT add `opentelemetry`, `opentelemetry_sdk`, or `opentelemetry-otlp`.
- **Workspace dependency centralization** (`Cargo.toml:24-42` + every crate's Cargo.toml): all version pins live in `[workspace.dependencies]`; per-crate Cargo.toml uses `dep.workspace = true` to opt in. Chunk #16 adds `tonic`, `prost`, `opentelemetry-proto` to workspace dependencies first.
