## Patterns detected

- **Prop-ref forwarding for long-lived rAF loop** (`HaloCanvas.tsx:63-70`): props mirrored into refs so `createFrameLoop`'s `onFrame` reads fresh data without pipeline teardown. New props follow the same `xxxRef` shape.
- **Two-path frame loop** (`canvas/frame-loop.ts:19-26` + `HaloCanvas.tsx:160-206`): animated rAF vs `onReducedMotionFrame` single-paint; reduced-motion repaint effect re-invokes the loop on data change so hue updates while motion stays suppressed. Reuse unchanged for the new inputs.
- **CSSOM design-token → WGSL uniform** (`HaloCanvas.tsx:51-55,107-108,124-138`): hex read via `getComputedStyle` at pipeline init, passed to `lchInterpolate`, written into the uniform buffer; no color literals in the shader (enforced by design-tokens.md 2026-05-08).
- **32-byte uniform with spare capacity** (`halo.wgsl:24-30` + `HaloCanvas.tsx:41-44,128-137`): `color(16) + blur_target(4) + pulse_phase(4) + 2×pad(8) = 32`. New scalar uniforms (connection-dim, opacity-target) fit the 2 pad slots with no buffer resize.
- **PULL-only real-data hooks** (`use-connection-state.ts`, `use-findings.ts`): both poll their TauRPC procedure on mount + window focus, `.catch(()=>{})` for jsdom; no Channel subscriber yet. The Halo's new inputs read from these (no new IPC).
- **Single Halo mount + composition-over-extension** (`AggregatedBadgeCanvas.tsx`): the badge overlays HaloCanvas as a sibling; only the canvas's prop contract changes.

## Conventions to follow

- **`IncidentSeverity` import, never bare `Severity`** — bindings.ts:75-80 documents the rename; bare `Severity` is the connection-domain enum (`info/warning/critical`). (session-learnings 2026-05-26)
- **Inline WebGPU spec constants as numeric literals** — `UNIFORM_BUFFER_USAGE = 0x40 | 0x08` (HaloCanvas.tsx:49) sidesteps jsdom's missing `GPUBufferUsage`. Any new buffer-flag use follows this. (testing.md 2026-05-09)
- **`<section aria-label>` implicit region** — never add explicit `role="region"` (eslint `no-redundant-roles`). (a11y.md 2026-05-09)
- **Co-located vitest, `as never` for overloaded DOM-method mocks, `vi.useFakeTimers()` not `sleep`** — per testing.md 2026-05-10/05-14.
- **jsdom WebGPU-constant fragility** — prefer module-level numeric literals over `vi.stubGlobal("GPUBufferUsage", …)`. (testing.md 2026-05-09)
- **Halo continuous animation exempt from chrome duration tokens** — do not apply `--duration-fast/standard`. (design-tokens.md §Motion)
