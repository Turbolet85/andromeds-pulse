## Patterns detected

- **Hook point** (`inference_runtime.rs:127-147`): extend the `L4DigestOutcome::Success(parsed)` arm so non-ResolutionSummary digests route to a new `create_incident_from_l4_output(...)` (mirroring how ResolutionSummary routes to `attach_resolution_summary_to_incident`).
- **Scrub→persist template** (`inference_runtime.rs:487-523`): `serde_json`/field-level `scrub_attribute` → persist → `error_category()` on failure, with defensive early-returns. The producer reuses this discipline field-by-field on `title`/`detail`.
- **Persistence-then-insert ordering** (`persistence.rs:101-105` + `registry.rs:64-67`): `save_new_incident(&incident) -> rowid` → `incident.id = rowid` → `registry.insert(incident)`. Corpus is durable source-of-truth; DashMap registry is live state read by the constellation join.
- **Re-emission dedup** (`registry.rs:118-120` + `list_active`): before creating, check `list_active(workspace)` for an existing non-Resolved incident matching the cool-down identity tuple `(kind, scope, workspace)` (+ optionally `fingerprint`); if found → `observe_reemission(id, now)` (+ persist update) instead of creating a duplicate. Prevents incident spam from repeated cue-triggered digests.
- **Single triggering cue** (`assembler.rs:250`): one `triggering_cue` per digest → `digest.attention_cues` is 0-or-1 element → no multi-cue ambiguity for which scope_id attributes the incident.
- **Activation is registry-direct** (`main.rs:684-688`): the per-service severity join reads the in-memory `incident_registry`, so `registry.insert` lights up the constellation hue synchronously — the `pulse://stream/incidents` broadcast is NOT on the activation path.
- **Aggregate-only obs** (`persistence.rs:43-53`): `TARGET_INCIDENT_PERSIST = "triage.incident.persist"`; new producer target follows the same bounded-field convention (counts + enum tags; never `scope_id`/`service_name`).

## Open questions (for Phase 6 / user — surfaced per CLAUDE.md 2026-05-30 data-producer discipline)

1. **[CENTRAL] Activation completeness / cue-scope_id sourcing.** The chunk's headline ("activates chunk-#91 per-service severity") requires the produced incident to carry the real service `scope_id`, but `DigestCueRef` drops it (folded into free-text `summary`). Three resolutions: **(A) Extend scope** — thread `scope`+`scope_id` structurally through `DigestCueRef` + populate in the chunk #81 assembler so the constellation hue lights up at runtime (small additive triage change; the route text "persist **with cue scope_id**" implies this is in-scope); **(B) Forward-inert** — build the full producer but leave `scope_id = None` → incidents become real (Findings counter / dropdown / report all populate) but constellation per-service hues stay baseline until a later threading chunk; **(C) Defer** chunk #92 behind a prerequisite scope_id-threading chunk. **Recommendation: A** (faithful + the threading cost is small because the scope_id is already in hand at the assembler).
2. **Creation predicate.** Which `(decision, severity)` combinations create an incident? Recommended default: `Decision::Surface` → Active incident; `Decision::Watch` → a `Curious`-tier incident (recorded, low-interrupt per `PriorityTier::Curious` semantics); `Decision::Dismiss` OR `severity == None` → no incident; `is_resolution_summary == true` → existing resolution-summary path (unchanged).
3. **Severity enum mapping.** `interpretation::Severity` → `triage`: `priority_tier` maps 1:1 (Autonomous→Autonomous, Suggested→Suggested, Curious→Curious); `severity` maps Autonomous→`Error`, Suggested→`Warn`, Curious→`Info` (`Critical` reserved for future escalation). Confirm or adjust.
4. **Dedup.** Recommended: re-emission dedup on `(kind, scope, workspace)` via `observe_reemission` to avoid incident spam (vs always-create).
5. **Creation broadcast.** Recommended: do NOT emit `IncidentLifecycleEvent` on creation (its shape is transition-oriented, its webview consumer is deferred, and activation works via `registry.insert` which the join reads directly) — keeps boot wiring unchanged + avoids a boot-smoke gate.
