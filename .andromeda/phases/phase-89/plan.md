## Implementation notes

1. **Order sensitivity:** land the `crates/triage` `DigestCueRef` field addition (Steps 1-2) FIRST so the `pulse-app` producer (Steps 3-4) can read `digest.attention_cues[0].scope_id`/`.scope`. The compiler will enumerate every `DigestCueRef { … }` struct literal needing the two new fields (additive `#[serde(default)]` keeps corpus BLOB backward-compat; the literals still need the fields at construction).
2. **No-triggering-cue digests:** some digest kinds (baseline / reflection cadence) carry an empty `attention_cues` vec. The producer needs a `(kind, scope, scope_id)` to build the Incident; when there is no triggering cue, prefer to **skip creation** (these non-cue digests are not service-attributable incidents) rather than invent a default `CueKind`. Confirm this skip at /implement Step 1 — it keeps incidents strictly cue-derived per the `Incident.kind` doc ("incidents derive from attention cues").
3. **`scope_id` scrubbing:** `AttentionCue.scope_id` is a bounded `service.name`, but route it through `scrub_attribute` at the persist boundary anyway (defense-in-depth — a service name could theoretically embed a secret) for both the `DigestCueRef` carry-through (Step 1) and the `Incident.scope_id` population (Step 4). The constellation join matches on the (scrubbed) string, so scrubbing must be deterministic/idempotent for a given input (it is — `scrub_attribute` is pure).
4. **Default decisions baked in (research.md §Open questions Q3-Q5), adjustable at /implement Step 1:** severity mapping (Autonomous→Error, Suggested→Warn, Curious→Info; Critical reserved); dedup via `observe_reemission` on `(kind, scope, workspace)`; NO `IncidentLifecycleEvent` emitted on creation (transition-oriented shape + deferred webview consumer; activation works via `registry.insert`).
5. **Dead-test discipline:** all producer tests go in `pulse-app/tests/*.rs`; a `#[cfg(test)] mod tests` in `pulse-app/src/inference_runtime.rs` would silently never run (`[lib] test = false`). The existing file already documents this (inference_runtime.rs:559-562).
