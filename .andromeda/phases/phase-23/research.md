## Patterns detected

- **Constant-string sanitization at From impl (`crates/ui-bridge/src/contract.rs:39-92`):** every From impl arm collapses upstream `reason: String` / `kind: &str` / `payload_bytes: usize` fields to a hard-coded one-liner (`"OTLP receiver bind failed"` / `"buffer init failed"` / `"viz query failed"` / etc.) — never `format!`-ing source error fields into the wire message. Tests pin this with `!message.contains("/private/")` / `!message.contains("0xdeadbeef")` / `!message.contains("1.10502")` invariants per test in `mod tests`.
- **VizError taxonomy split (`contract.rs:74-92`):** `VizError::QueryFailed/ConnectionLost/Decode` route to `AppError::Storage` (storage class), while `VizError::InvalidArgument { field, .. }` routes to `AppError::Validation { field, reason: "invalid query argument" }` preserving the caller-known `field` identifier and replacing `reason` with a constant. Confirms arch §Established Decisions [Error Handling Pattern] taxonomy: storage queries → Storage, user-supplied parameter rejection → Validation.
- **Test naming `from_<source>_<scenario>_<assertion>` (`contract.rs:99-368`):** every test follows `from_{ingest_variant}_collapses_to_constant_message` / `from_buffer_init_collapses_to_constant_message_no_struct_name_leak` / `from_viz_decode_collapses_to_constant_message_no_struct_name_leak` — explicit suffix-discipline that documents the assertion class (constant_message / no_struct_name_leak / no_reason_leak / no_byte_count_leak / preserves_field).
- **Serde wire shape verified at `contract.rs:99-107` + `:340-350`:** existing pattern uses `serde_json::to_string(&e).expect("serializes")` then `serde_json::from_str(&s).expect("parses back")` to round-trip + assert on decoded `serde_json::Value` field paths (`v["kind"] == "ingest"` / `v["message"] == "..."`). Currently only Ingest + viz QueryFailed have explicit round-trip tests; round-trips for Validation / NotFound / Internal / Plugin / Storage / Ingest standalone variants (without From impl) are gap.
- **Heartbeat invariant assertions (`contract.rs:352-368`):** `from_invariant_message_does_not_leak_kind_or_lengths` walks the serialized JSON STRING (`!s.contains("trace_id_length")` / `!s.contains('8')`) — secondary defense layer beyond the structural variant match. Pattern to replicate for new placeholder From impls.
- **Workspace dep `tracing` 0.1 declared but ui-bridge does not use it (`Cargo.toml workspace + ui-bridge Cargo.toml`):** `tracing = "0.1"` is in workspace `[dependencies]` (line 31 of root `Cargo.toml`); existing crates that emit telemetry (ingest, buffer, viz, pulse-app) all have `tracing.workspace = true` in their `[dependencies]`. ui-bridge does not — adding tracing emission to From impls per obs §10 requires extending ui-bridge's `[dependencies]` table.
