## Conventions to follow

- **Sentinel canary strings**: `__TEST_REDACTION_CANARY_<id>__` (where `<id>` is per-test distinctive) for PII negative-canary inputs. NEVER use realistic-looking secrets in test fixtures (testing.md §11 Universal + chunk #77 tests extract anti-pattern bullet).
- **`tracing::warn!(target: …)` literal `target` discipline** (testing.md 2026-05-10): `target:` arg MUST be `&'static str` literal. For parametric tests across N targets, unroll into N sibling `#[test]` fns.
- **Async tracing capture: `set_default` not `with_default`** (testing.md 2026-05-09): `#[tokio::test]` async resolvers use `let guard = tracing::subscriber::set_default(subscriber); …; drop(guard);` pattern. `with_default(closure)` panics с "Cannot start a runtime from within a runtime" in async contexts.
