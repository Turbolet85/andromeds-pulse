## Open questions

1. **`~/Downloads` out-of-data-dir target (KEY — surface at Phase 6).** arch + layouts + security all flag that `~/Downloads/pulse-corpus-export-{timestamp}.jsonl` is OUTSIDE the data-dir canonicalization boundary and unspecified by existing plans. **Recommended resolution:** procedure takes `target_path: Option<String>`; when `None`, the resolver computes `<home>/Downloads/pulse-corpus-export-{ts}.jsonl` (home via `std::env` `USERPROFILE`/`HOME` or `dirs` if already a transitive dep — NO new workspace dep); the path is `canonicalize()`d on its PARENT + parent-dir-existence asserted before write; traversal rejected → `AppError::Validation`. **NO native OS file picker this chunk** — `tauri-plugin-dialog` would add the three-way Rust+npm+capability dep trio, violating "workspace deps delta = none"; a picker is a documented deferred enhancement. The data-dir-confinement invariant does NOT apply to this deliberate user-chosen export sink (documented as an explicit exception in the arch-registry amendment).
2. **Preview-before-write gate (surface at Phase 6).** The route signature `storage.export_for_training(target_path)` is ambiguous on how preview-without-write is expressed. **Recommended:** add a `confirm: bool` (or `preview_only: bool`) second arg — `confirm=false` returns the preview summary WITHOUT writing; `confirm=true` writes the JSONL + returns the summary with a `written: bool` + `written_path_basename`. This cleanly satisfies the tests "no file written until explicit confirmation" gate and keeps it one procedure (honoring "+1 TauRPC procedure"). Slightly exceeds the bare route signature → flag to user.
3. **Export data source = incidents table (all statuses, all workspaces).** The "per record" unit = one incident. Resolved incidents carry the full L4 `resolution_summary_text` (model interpretation); active ones carry trigger context only (`resolution_summary_text` null). `load_all_incidents()` reads ALL rows (no status/workspace filter) for a full corpus dump. Preview "count by category" = count-by-status + count-by-severity (the chosen category dimensions). Digests (`digest_archive`) are NOT exported (no `load_digest` read method exists; incidents are the richer L5 record). Confirm this scope at Phase 6.
4. **Nested modal (minor).** The export preview `<Modal>` opens over the Settings `<Modal>` (two focus traps). focus-trap-react v12 stacks traps (pauses parent). Acceptable; tests follow the chunk #33/#37/#38 FocusTrap patterns (`displayCheck:'none'` already in Modal). If trap-stacking proves fragile in vitest, fall back to a single in-section confirm step with `aria-modal` semantics — noted for /implement.
