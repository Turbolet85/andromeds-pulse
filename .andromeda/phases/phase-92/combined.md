Settings → Storage → "Export for community training" action that produces an anonymized JSONL dump from the corpus (anonymized trigger context, model interpretation, user feedback, resolution outcome per record). A pre-write preview dialog displays a summary (count by category, date range, anonymization confirmation) before the file write; default target `~/Downloads/pulse-corpus-export-{timestamp}.jsonl`; NO auto-submission — user manually shares. Capability P-046, L5 export channel. Deps #69 (corpus) + #78 (incident records) + #47/#72 (PII scrubbing). +1 TauRPC procedure `storage.export_for_training(target_path)`; workspace deps delta = none; arch registry delta = +1 procedure.
