## Patterns detected

- **Co-located test pattern** (`pulse-app/ui/src/canvas/CanvasContainer.test.tsx`, `frame-loop.test.ts`, `frame-metrics.test.ts`): each source file has a sibling `*.test.{ts,tsx}` running through `vitest run`. Vitest discovers via `include: ["src/**/*.{test,spec}.{ts,tsx}"]`.
- **WebGPU module-mock pattern** (`canvas/CanvasContainer.test.tsx:4-29`): `vi.mock(...)` factories at top-of-file return stubbed pipeline factories + `recordFrameMs` + `useReducedMotion`. Imports come AFTER mocks via `await import(...)`. `afterEach` calls `vi.unstubAllGlobals()` + `vi.mocked(fn).mockClear()` per dependency.
- **Tagged-union return pattern for failable initialization** (`canvas/webgpu-adapter.ts:20-30`, `canvas/compute-pipeline.ts:22-30`): consumer branches on `result.kind === "available" | "unavailable"` or `"created" | "failed"`. Failure reason is a finite-string allowlist (no raw error message exposed).
- **WGSL `ColorUniforms` + Vite `?raw` import** (`canvas/shaders/metrics-chart.wgsl:6-13`, `canvas/render-pipeline.ts:11-13`): shaders are first-party assets bundled at build time; design tokens become `vec4<f32>` uniforms uploaded to bind group 0 binding 0 — NEVER inline RGB literals (per design-tokens.md Session Additions 2026-05-08).
- **Reduced-motion gate at the rAF tick layer** (`canvas/frame-loop.ts:21-24` + `canvas/CanvasContainer.tsx:107-118`): when `prefersReducedMotion === true`, `start()` invokes `onReducedMotionFrame` exactly once + does NOT schedule `requestAnimationFrame`. Consumer responsibility: re-call `start()` on data change to trigger static repaint with new state. Hue updates remain (motion suppressed, data signal preserved).
- **Frame-metric stable 4-field shape across motion modes** (`canvas/CanvasContainer.tsx:99-118`, `canvas/frame-metrics.test.ts:144-160`): both rAF and reduced-motion code paths invoke `recordFrameMs` with the same 4 keys (`duration_ms` / `wgpu_backend` / `webview_backend` / `timing_method`). Reduced-motion path uses `duration_ms: 0` + `timing_method: "cpu"` — keeps obs `metric.webgpu.frame_duration_ms` jq aggregation continuing over a sparser stream.
- **Semantic `<region role="region" aria-label="...">` wrapper around `<canvas>`** (`canvas/CanvasContainer.tsx:130-143`): canvas itself has zero a11y tree presence; wrapper carries role + label. Same pattern applies to Halo per a11y extract §1 desktop-webview row.
- **TauRPC dotted-namespace proxy access** (`canvas/frame-metrics.ts:96-112`): `proxy.telemetry?.frontend?.record_frame_ms?.(input)` via runtime nested-proxy walk. Per frontend.md Session Additions 2026-05-09: 3-segment dotted namespaces (`telemetry.frontend`) work end-to-end via taurpc's nestedProxy prefix-match cascade.
- **Settings extension pattern (no new IPC)** (`bindings/index.ts:31`): chunk #30 added `always_on_top` to `Settings`. Future user-tunable Halo state (e.g., disable toggle) follows same pattern — NEW TauRPC procedure NOT required.

## Conventions to follow

- **TypeScript strict, no `any`**, no `as` casts unless justified with one-line comment (per global CLAUDE.md). The `as unknown as` double-cast pattern is reserved for proxy/stub surfaces with documented rationale (`canvas/frame-metrics.ts:98`).
- **ES modules** (`import`/`export`) — config files OK as `.mjs`/`.cjs` exception.
- **React 19 functional components**, destructured imports (`import { useEffect, useRef, useState, type ReactNode } from "react"`).
- **Vite `?raw` for WGSL inline-import**: `import shaderName from "./shaders/name.wgsl?raw"` — pattern in `render-pipeline.ts:11-13` + `compute-pipeline.ts:15`.
- **Design-token consumption via CSS variables**: `style={{ background: "var(--color-inset)", borderRadius: "var(--radius-md)", padding: "var(--spacing-md)" }}` (`CanvasContainer.tsx:134-137`). For WGSL uniforms: read at JS init via `getComputedStyle(document.documentElement).getPropertyValue('--color-X')`, parse to `vec4<f32>`, write into uniform buffer.
- **File naming**: `kebab-case.ts` for utility/hook modules; `PascalCase.tsx` for React components; `kebab-case.wgsl` for shaders.
- **Test naming**: descriptive English-style sentences as `it(...)` titles ("renders <region> wrapper with the provided aria-label", "respects prefers-reduced-motion: reduce by suppressing the rAF loop"); mirrors Rust convention `test_<entity>_<scenario>`.
- **Sanitized error one-liners across the JS↔Rust boundary** (`canvas/render-pipeline.ts:23-29`, `canvas/webgpu-adapter.ts:64-67`, `canvas/compute-pipeline.ts:39`): try/catch + re-throw with stable identifier OR collapse to allowlist-discriminator string. NEVER `error.stack` / `error.fileName` / raw `error.message` propagation.
