## Implementation Steps

1. **Pure-function mappers** — write three small modules under `pulse-app/ui/src/halo/` with co-located tests:
   1. `throughput-to-hz.ts` exporting `throughputToHz(throughputHz: number): number` returning `clamp(throughputHz / 1000, 0.8, 2.4)`. Handle `NaN` / `Infinity` / negative input by collapsing to `0.8` (lower bound) per design extract clamp ownership. Co-located `throughput-to-hz.test.ts` table-drives the input set per combined.md tests acceptance row.
   2. `error-rate-to-blur.ts` exporting `errorRateToBlur(errorRate: number): number` returning `lerp(4, 16, clamp(errorRate, 0, 1))` — this returns the OUTER ENVELOPE (current target blur magnitude). The mid-cycle sinusoidal blur sweep is the WGSL fragment shader's job (modulating around the target). Co-located `error-rate-to-blur.test.ts` table-drives.
   3. `lch.ts` exporting `lchInterpolate(errorRate: number, primaryHex: string, accentHex: string): { r: number; g: number; b: number; a: number }` using `colorjs.io` 0.6.0 LCH interpolation (`new Color(hex).range(new Color(hex), { space: "lch" })(t)`). Returns sRGB float quadruple (0..1) ready for `vec4<f32>` upload. Co-located `lch.test.ts` asserts: error_rate=0 → Earth Blue `#4A90E2`; error_rate=1 → Alert Burgundy `#C7556A`; error_rate=0.5 lands on the LCH geodesic (NOT the RGB midpoint `~#896E96` — assert specific `r` / `g` / `b` floats with reasonable tolerance per design extract acceptance criterion); clamps at boundaries.

2. **Type definitions** — write `pulse-app/ui/src/halo/halo-types.ts` exporting `HaloInput { throughputHz: number; errorRate: number }` + `MotionMode = "animated" | "static_glow"`. Used across modules + test fixtures.

3. **WGSL shader** — write `pulse-app/ui/src/halo/shaders/halo.wgsl` with:
   - `HaloUniforms { color: vec4<f32>, blur_target: f32, pulse_phase: f32, _pad: f32 }` at `@group(0) @binding(0) var<uniform>` (the trailing `_pad: f32` keeps the struct 16-byte aligned per WGSL std140-like rules — verify with WebGPU spec if alignment-sensitive).
   - Vertex shader: standard fullscreen-quad mirror of `metrics-chart.wgsl::vs_main` (6-vertex triangle list, `position` + `uv` output).
   - Fragment shader: radial gradient centered at `uv == vec2<f32>(0.5, 0.5)`. Compute `dist = length(in.uv - vec2(0.5))`. Compute current blur via `current_blur = blur_target * (0.5 + 0.5 * sin(pulse_phase))` — sweeps around the target per design's sinusoidal envelope (0.6-1.2s breath period inverse of frequency). Output `vec4<f32>(color.rgb, color.a * smoothstep(0.5, 0.5 - current_blur / 64.0, dist))` (or equivalent radial-falloff math — implementer chooses concrete falloff; the spec is "blur radius 4-16 px sweeps sinusoidally"). NO inline RGB literals (only structural-zero `vec4<f32>(0.0, ...)` is allowed per design-tokens.md Session Additions 2026-05-08).
