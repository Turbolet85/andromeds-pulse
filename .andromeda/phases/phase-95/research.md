## Patterns detected

- **Tier-branched prompt selection** (`pulse-app/src/inference_runtime.rs:306-315`): `match runner.tier() { Primary => build_primary_tier_prompt(...), Fallback => build_fallback_tier_prompt(...) }`. The reflection variant slots in as an ADDITIONAL discriminator (`digest.kind == DigestKind::Reflection`) composed with tier.
- **Prompt-builder shape** (`crates/interpretation/src/prompt.rs:110-254`): each builder = `String::with_capacity(...)` + section pushes (Role / Conventions / Schema-with-version-metadata / Project Context markers / Digest markers / optional Corpus markers / Output Instructions). A reflection builder mirrors this with trend-emphasis Role + Output constants.
- **Window-by-mode** (DUPLICATED at `coordinator.rs:235` `cycle_window_for` + `digest_runtime.rs:203` `cycle_window_for_mode`): both already return 1800s for Reflection. (Minor: duplication exists; not chunk #98's concern to dedup.)
- **Non-cue digest skip** (`inference_runtime.rs:631-636`): incidents are strictly cue-derived + service-attributable via `scope_id`; reflection/baseline digests have no cue → no incident. This is the deliberate chunk #91/#92 invariant the element-(4) decision must respect or relax.
- **Aggregate-only L4 tracing** (`inference_runtime.rs` TARGET_* consts): `interpretation.inference.request` carries bounded `digest_kind` + `model_tier` + `result` + `duration_ms` only — a reflection-mode prompt-version field (`prompt_version`) is already emitted at `TARGET_L4_PROMPT_ASSEMBLE` (319) and naturally distinguishes reflection.
- **Pure-function prompt tests** (`prompt.rs:256-548`): string-contains assertions + section-ordering + negative-canary; framing-text-exclusive discriminators per CLAUDE.md 2026-05-25 (avoid substrings that appear in the embedded `include_str!` schema.json).
