## Per-chunk extracts

### Chunk route#98: "Background reflection cadence"

**Source detail (docs/v0_2_0/pulse-v0_2_0-route.md §96):** Cadence Coordinator (#80) emits a reflection-mode trigger every 1800s (configurable). Digest assembler builds a 30-minute-window digest instead of the 60s slice. L4 prompt for reflection mode emphasizes cumulative trend analysis over acute interpretation. L5 surfacing: reflection-produced incidents default to Curious severity unless the model identifies a high-confidence pattern warranting Suggested or higher. Cancellation: reflection skipped (NOT queued) if the LLM is busy with higher-priority work. Depends on #81 (digest + LWW queue) + #83 (L4 inference) — both landed. **TauRPC / broadcast / workspace-deps / arch-registry deltas: all NONE.** Distillation layer L3 + L4 (long-window mode). Optional/defer-friendly per source ("Drop from v0.2.0 if scope tight").
