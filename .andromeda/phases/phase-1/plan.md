## Combined goal

Materialize the Cargo workspace + Tauri 2 scaffold that every subsequent Foundation chunk and every feature epoch depends on, locking ten reserved crate names (`ingest`, `buffer`, `viz`, `ui-bridge`, `snapshot`, `workspace-detector`, `plugins`, `mcp-server`, `pulse-app`, `xtask`) at the workspace level and pinning `rustc 1.85+ Edition 2024` so security-positive defaults (`unsafe_op_in_unsafe_fn`, tightened `if let` temporary scopes) are in force from the first commit. The workspace also declares the obs `tracing`-family dependencies (`tracing` 0.1, `tracing-subscriber` 0.3 with `json+env-filter`, `tracing-appender` 0.2, `tracing-error` 0.2) and reserves the `mcp-server` and `otap-ingest` cargo features default-off — so the no-OTel-SDK self-observation invariant and the feature-gate hygiene rule are enforceable from `cargo deny check bans` onward (per arch §Inherited Defaults + obs plan §3 + security plan §Anti-Patterns Universal + tests plan §3 Bootstrap).

The Tauri 2 layer (chunk #2) lands the binary scaffold inside `pulse-app/` — `tauri.conf.json` with bundle identifier `com.andromeda.pulse` (the obs `service.name` source-of-truth + a11y violation JSON tag), CSP `script-src 'self'` with `worker-src 'self' blob:` for WebGPU, frameless windows for the compact widget + full dashboard surfaces, and the negative-default capability JSON inventory (`pulse:default`, `pulse:tray`, `pulse:notification`, `pulse:updater`, `pulse:plugin-fs`) that the `xtask capability-drift` check will diff against TauRPC routers from chunk #4 onward. The webview source root `pulse-app/ui/` is established with `<html lang="en">` + a single `<main>` landmark so SC 3.1.1 and SC 4.1.2 baselines hold from the first render — no design tokens or a11y harness yet (those land at routes #10-#15) but the substrate must not preclude them.

The pre-baked agent-run.sh / agent-run.ps1 harness already encodes the binding contract (`cargo run --bin pulse-app`, `cargo xtask harness:status`, `cargo nextest run --workspace --profile ci`, env vars `ANDROMEDA_PULSE_*`); chunks #1-#2 must satisfy its assumptions without modifying it. After this phase, `cargo check --workspace --all-targets` and `cargo deny check bans` pass against an empty-but-structurally-correct workspace; `cargo nextest run --workspace --profile ci` resolves with zero tests; the Tauri 2 binary builds (`cargo tauri build` — though full bundle output deferred to chunk #3 once signing keys land).
