## Patterns detected

- **Halo State Pulse pattern (chunk #31 baseline)**: per-canvas WebGPU pipeline + 32-byte uniform buffer + per-frame uniform write (color via `lchInterpolate`, blur via `errorRateToBlur`, phase via `throughputToHz` + timestamp). Multi-service extension means EITHER (a) one canvas per service-dot with independent pipeline, OR (b) one shared canvas with N draw calls per frame (one per service). Per layouts §Decisions Log "Signature placement strategy", chunk #34 wants (b) for the constellation metaphor — single canvas, N halo dots distributed by service topology.
- **Single-canvas-N-instances pattern**: WebGPU instanced rendering or N draw calls per frame, with per-instance uniforms. The HaloCanvas current pipeline draws 6 vertices once per frame (full-screen quad). Multi-service constellation will need to either re-call `pass.draw(6)` N times with per-service uniform writes, OR adopt instanced rendering via `pass.draw(6, N)` with a per-instance storage buffer. Either approach reuses the same shader pipeline.
- **TauRPC binding consumption pattern (chunks #28/#29)**: `import { createTauRPCProxy } from './bindings'` → `const proxy = createTauRPCProxy()` → `proxy.traces.query(args)` returns `Promise<PaginatedResponse<TraceRow>>`. AppError discriminated union surfaced as the rejection.
- **Channel API decode pattern (chunk #23 producer side, #34 first consumer)**: `Channel<Vec<u8>>` carries binary Arrow IPC; webview decodes via `arrow-js` (or `apache-arrow` JS package per `.claude/rules/frontend.md`). The `subscribe_*` IPC takes a `Channel` callback; webview-side `Channel` constructor receives `Uint8Array | number[]` payloads.
- **Sort-state announcement pattern**: bind to existing `StatusLiveRegion` from chunk #33; sorting "Latency descending" → `announce("Sorted by Latency, descending")` via the polite region.
- **Test mock pattern for canvas-dependent components (chunk #33 precedent)**: `vi.mock("../../canvas/CanvasContainer", () => ({ CanvasContainer: ({ariaLabel}) => <section aria-label={ariaLabel} data-testid="..."/> }))` — stubs the WebGPU-mounting component as a sentinel `<section>`. Apply same pattern for ConstellationCanvas tests.
- **TraceRow extension pattern (none yet — new for chunk #34)**: extending viz `TraceRow` is FRESH ground. The existing struct is at `crates/viz/src/{lib,query,state}.rs`; need to add `service: String, duration_ms: u64, error_count: u32` (or similar) with `serde::Serialize` derive. The query path in `crates/viz/src/query.rs` populates rows from DuckDB; new fields require DuckDB schema (already exists per chunk #20 — `spans` table has `service_name`, `start_time_unix_nano`, `end_time_unix_nano`, `status_code`); extension is at the query SELECT + row decode layer, not a schema migration.
