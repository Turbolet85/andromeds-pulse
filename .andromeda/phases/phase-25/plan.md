## Combined goal

Chunk #28 lands the WebGPU rendering substrate that Epoch 5's nine downstream chunks (#29-#37) consume. The substrate has four parts: (a) `navigator.gpu` adapter detection with graceful-degrade fallback (mirrors `ANDROMEDA_PULSE_MCP_ENABLED` precedent per arch §Established Decisions); (b) three WGSL render-pipeline factories aligned to the viz query routers (`traces.*` → trace timeline + flamegraph; `metrics.*` → metrics charts; `logs.*` reserved for chunk #35); (c) a semantic React canvas wrapper (`role="region"` + `aria-label`) carrying design-token chrome (`--color-inset` bg, 1px subtle border, `radius-md`, `space-md` padding) and respecting `prefers-reduced-motion: reduce` via the chunk #15 `useReducedMotion` hook + chunk #15 `createFrameLoop` reduced-motion-gated rAF; (d) a fallback message component (`role="alert"`) rendered when `navigator.gpu` is undefined or `requestAdapter()` returns null, screen-reader-accessible via `aria-live="assertive"`.

The chunk is substrate-only: no per-surface composition (compact widget hero / full dashboard hero / tray icon overlay all land at chunks #30/#31/#33/#34/#35/#36) and no per-frame timing telemetry (the TauRPC `telemetry.frontend.record_frame_ms` resolver lands at chunk #29 with the 10k spans/sec compute aggregation budget). Chunk #28 wires the frame-timing measurement point in the rAF tick and registers the `metric.webgpu.frame_duration_ms` AllowList entry so chunk #29 can attach the resolver without re-architecting the render loop. Per security plan §API Security CSP row + §Threat Model Summary "webview content" all WGSL shader sources are first-party-bundled (`'self'` origin); no remote shader CDN, no `'unsafe-inline'`/`'unsafe-eval'` script-src widening; no `pulse:default` capability changes.
