## Patterns detected

- **Mirror-the-widget migration** (`pulse-app/ui/src/widget/ConstellationCanvas.tsx`): the dashboard ConstellationCanvas should become a near-copy of the widget one — same `visibleDots`/`constellationSummary`/`createConstellationPipeline` machinery, differing only in the fixed 240px hero height (vs `100%`) and `data-testid`. The shared `widget/constellation-types.ts` + `widget/constellation-pipeline.ts` are reused verbatim across both surfaces (three-surface coherence).
- **CSSOM token-read + lchInterpolate** (`HaloCanvas.tsx:64–68,127–128` + both ConstellationCanvas files): `readDesignToken("--color-primary","#4A90E2")` / `("--color-accent","#C7556A")` at pipeline init → `lchInterpolate(hueFraction, primaryHex, accentHex)`. No hardcoded hex in shaders.
- **Frame-metrics bridge** (`canvas/frame-metrics` → `recordFrameMs`, both ConstellationCanvas files): `onFrame` times `performance.now()` + `device.queue.onSubmittedWorkDone()`; `onReducedMotionFrame` records `duration_ms: 0`. The migration preserves this verbatim.
- **Reduced-motion via createFrameLoop** (`canvas/frame-loop`): `prefersReducedMotion` + `onReducedMotionFrame` render one static frame (full envelope) — severity/brightness still encode state. Widget pattern; dashboard mirrors.
- **jsdom-silent TauRPC hooks** (`use-service-constellation.ts`, `use-widget-metrics.ts`): `.catch(()=>{})` on every proxy call; the dashboard inherits this for free by reusing `useServiceConstellation`.
- **`<section aria-label={…}>` implicit region** (a11y rules 2026-05-09): the wrapper uses `aria-label` WITHOUT explicit `role="region"` (redundant-role lint); the dashboard switches its static `aria-label="Service constellation"` to the dynamic `constellationSummary(items)` sentence for the not-color-alone text equivalent.
