## Implementation Steps

### Step 1 — Add TanStack Router dependency

Add `@tanstack/react-router` to `pulse-app/ui/package.json` under `dependencies`. Pin to a specific minor version (e.g., `^1.x` resolved by lockfile). Run `npm install` in `pulse-app/ui/` to update `package-lock.json` and `node_modules/`. Use the manual createRouter API (no Vite plugin) — 5 routes only; defer codegen complexity per Open Question Q3 in research.md.

### Step 2 — Create TanStack Router setup

Create `pulse-app/ui/src/dashboard/router.tsx` defining 5 routes (`/traces`, `/metrics`, `/logs`, `/snapshots`, `/settings`) mapped to the 5 route components. Default route: `/traces`. Use `createRouter({ routeTree, history })` with browser history for the production webview and memory history for tests (`createMemoryHistory({ initialEntries: ['/traces'] })`). Export `Router` instance + `<RouterOutlet>` consumer hook for Dashboard.tsx integration.

### Step 3 — Create 5 route component stubs

Create `pulse-app/ui/src/dashboard/routes/{TracesRoute,MetricsRoute,LogsRoute,SnapshotsRoute,SettingsRoute}.tsx`. Each renders `<section aria-label="...">` (implicit `role="region"` per a11y rule Session Additions 2026-05-09 — do NOT write explicit `role="region"`) + `<h1>` matching tab label + content. TracesRoute receives `haloInput` via Router context and renders the existing `CanvasContainer` + `HaloCanvas` peers (relocated from Dashboard.tsx per research.md Open Question Q2). Other 4 routes render the empty-state pattern: centered `telescope` icon (24px, `--color-text-tertiary`) + tone-appropriate message ("No metrics yet — chunk #35 fills this view" / similar). All inline styles consume design tokens — NO hex literals.

### Step 4 — Create TabNav component

Create `pulse-app/ui/src/dashboard/TabNav.tsx` using React Aria Components `Tabs`/`TabList`/`Tab` (NOT Headless UI per a11y-plan §11). Wrap in `<nav aria-label="Dashboard sections">`. 5 tabs in fixed order: Traces / Metrics / Logs / Snapshots / Settings. Active tab gets bottom border emphasis (`rgba(74,144,226,0.6)`) + font-weight 600 + filled-icon variant — at least 2 distinct visual cues per design AC + a11y not-color-alone (SC 1.4.1). Tab labels include custom Observatory icons (`telescope` for Traces, `aperture` for Settings; design plan §Iconography); generic Lucide fallback only if no domain glyph fits. On tab activation, navigate to corresponding route via TanStack Router `useNavigate`. Single tab stop into tablist with arrow-key navigation among tabs (React Aria handles roving tabindex automatically).

### Step 5 — Create SkipToMain component

Create `pulse-app/ui/src/dashboard/SkipToMain.tsx` rendering `<a href="#main-content">Skip to main content</a>` styled with Tailwind v4 utility classes hidden until `:focus-visible` (visually-hidden via `clip-path: rect(0,0,0,0)` + position absolute + 1px size; appears on focus via the standard CSS pattern). Mounted as the first focusable element in Dashboard shell per a11y AC + a11y-plan §5 Skip links / WCAG SC 2.4.1.

### Step 6 — Create CommandPalette component

Create `pulse-app/ui/src/dashboard/CommandPalette.tsx` using React Aria Components `Dialog` + `ComboBox` + `ListBox` inside `<FocusTrap escapeDeactivates returnFocusOnDeactivate>` (focus-trap-react 12). Bounded `palette_action_kind` enum: `open-tab` (one entry per route — 5 entries) initially; future kinds (`open-snapshot-modal`, `toggle-mcp`, `quit-app`) added in later chunks. NEVER use `dangerouslySetInnerHTML` for result rendering (security AC-S3); React's default text rendering escapes user input automatically. Palette mounted controlled-open via state lifted to Dashboard shell. Closes on Escape, restores focus to trigger. Overlay uses `--color-raised-3` background + `--radius-lg` (8px) + 1px subtle/emphasis border + 200ms ease-out fade (degrades to instant under reduced motion).

### Step 7 — Create global keyboard shortcut hook

Create `pulse-app/ui/src/dashboard/use-keyboard-shortcuts.ts`. Listens for: Cmd+K / Ctrl+K → toggle palette open state (lifted to Dashboard shell); Cmd+Shift+P / Ctrl+Shift+P → compact↔full toggle by calling `getAllWebviewWindows()` then invoking `.show()` on the inactive window + `.hide()` on the current window (no new TauRPC procedure; Tauri 2 webview API covered by `core:default` per research.md default.json read); Esc → close palette if open (otherwise no-op — the modal close discipline lives in palette's own Escape handler when other modals stack later). All listeners detached on unmount.

### Step 9 — Create StatusLiveRegion component
