## Implementation notes

- **Cycle-break:** trait+impl pairs MUST land in `pulse-app/src/streams.rs` (binary crate composition layer), NOT in `crates/buffer/src/`. Buffer's `taurpc-runtime` feature does NOT exist (chunk #22 deviation rationale: cargo feature unification creates real cycle when buffer would depend on ui-bridge for AppError). Mirrors `pulse-app/src/viz_routers.rs` precedent.
- **Pre-encode in `dispatch_batch`:** to avoid re-fetching from DuckDB after append, encode the Arrow `RecordBatch` directly from the input `Batch::Spans/Metrics/Logs` before the DuckDB append call. The buffer's `appender.rs` already converts the input into RecordBatches for the DuckDB Arrow appender — chunk #23 reuses those RecordBatches for broadcast encoding. Coordinate the order: encode BEFORE append (so encoder sees the same batch DuckDB will store), but only emit to broadcast AFTER append succeeds (so subscribers see only durably-stored data).
- **`Arc<Vec<u8>>` vs `bytes::Bytes`:** `bytes::Bytes` is cheap-clonable (refcounted slab). Prefer `bytes::Bytes` over `Arc<Vec<u8>>` for the broadcast Sender payload type — broadcast clones across N subscribers, and `Bytes::clone` is just an Arc bump rather than full Vec clone.
- **`Channel<Vec<u8>>` conversion:** at the `streams.rs` Channel-send site, convert via `bytes.to_vec()` (cheap because Bytes-backed Vec is already in single-owner state by then). Or use Channel<bytes::Bytes> if Tauri 2 accepts — verify at impl time, default to Vec<u8> if uncertain.
- **Receiver count tracking:** `tokio::sync::broadcast::Sender::receiver_count()` returns `usize` (live subscriber count). Heartbeat tick polls + sums + writes to IngestState.broadcast_subscribers. NOT reactive — accuracy is bounded by 15s tick cadence, which is acceptable for a heartbeat-driven gauge.
- **No need to alter `crates/ingest/src/state.rs`:** chunk #18 already added `broadcast_subscribers: AtomicU32` + `set_broadcast_subscribers(n)`. Chunk #23 only POPULATES this field from the heartbeat tick context (not a code change to ingest crate).
- **a11y throttle knob deferral:** documented in Acceptance Criteria a11y row 4. NO Decisions Log entry added to `.andromeda/route.md` Section 3 at chunk #23 — the deferral is internal to plan.md provenance + chunk #29 phase research will pick up the obligation. /implement does NOT touch route.md.
- **Consumer signature change is breaking for chunk #18-22 callers:** existing `run_consumer(receiver, conn, state)` → new `run_consumer(receiver, conn, state, broadcast_senders)`. Only one caller (pulse-app/src/main.rs:226). Update at impl time alongside main.rs Arc threading.
