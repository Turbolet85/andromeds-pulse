- **`#[tracing::instrument(skip(...))]` discipline**: skip non-allowlisted fields like `payload`/`batch`/`bytes`. Per obs rules + chunk #22 query path precedent.
- **Atomic-relaxed ordering for non-synchronizing counters**: per `crates/buffer/src/state.rs:32-48` (eviction_count, memory_bytes, etc.). Chunk #23's per-stream subscriber count uses `Ordering::Relaxed`.

- **Test naming: `{verb}_{condition}_{expected}` for unit tests; `{action}_{state}_{outcome}` for state tests**: per `pulse-app/src/heartbeat.rs::tests` precedent.
- **Strip-prefix matching against AllowList**: per `pulse-app/src/observability.rs::for_target:502-522` — `target.strip_suffix(".tick")` AND `target.split('.').next()` AND `target.split("::").next()`.
