## Patterns detected

- **Sidecar-as-separate-binary** (arch §Cross-cutting Patterns "Runtime topology" + `pulse-app/Cargo.toml:42-46`): the rmcp sidecar is the second binary in the workspace; `mcp-server-crate` aliased pkg + `optional = true` means the library code is in `crates/mcp-server/` AND the binary target lives there too — per arch §Inherited Defaults Module boundaries (libraries don't depend on binaries; new binary as sibling `[[bin]]` is the DAG-safe placement).
- **Workspace feature propagation** (`pulse-app/Cargo.toml:55-58` + `crates/plugins/` precedent): pulse-app's `mcp-server` feature only pulls the crate into the dep graph; the crate's OWN `mcp-server` feature is what gates `rmcp`. Per `arch §Cross-cutting Patterns "Feature-gate hygiene"` — chunk #48 needs `crates/mcp-server/Cargo.toml [features] mcp-server = ["dep:rmcp", ...]` AND pulse-app's `mcp-server = ["dep:mcp-server-crate", "mcp-server-crate/mcp-server"]` propagation.
- **Custom `FormatEvent` for default-fields + redaction** (`pulse-app/src/observability.rs` + .claude/docs/session-learnings.md 2026-05-03 entry): the obs-plan §3 "with_default_fields" + §8 "default-deny scrubbing" intents are satisfied via a single custom `FormatEvent` impl (`JsonWithDefaults`) that walks event fields with a redacting `Visit` impl AND prepends default identity fields. Sidecar follows this pattern — own `JsonWithDefaults` instance with sidecar-scoped `AllowList::for_mcp_server()`.
- **AllowList by-target resolver** (`pulse-app/src/observability.rs:99-200`): exact-match → strip-suffix `.tick` → `split('.').next()` → `split("::").next()`. New targets like `mcp.feature.gate.check` resolve via `split('.').next() → "mcp"`. Allowlist key MUST be the workspace crate name from arch §Occupied Resources (here: `mcp-server`) OR the dotted-target prefix `mcp` if no crate prefix collision exists. Decision for chunk #48: key the allowlist on `"mcp"` (event target prefix) — `mcp-server` crate name has a hyphen which is not a valid `target` prefix per tracing.
- **Tracing target as `&'static str` literal only** (.claude/rules/testing.md Session Additions 2026-05-10 + `pulse-app/src/observability.rs:585-620` `unroll_per_target` test pattern): tracing macros require literal target strings.
