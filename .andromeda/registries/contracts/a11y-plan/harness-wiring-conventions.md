### Harness wiring & conventions

- **Mock layer:** Playwright specs mock the Tauri IPC via `tests-a11y/helpers/mock-tauri.ts` — TauRPC procedures are invoked as `TauRPC__<router.path>` (taurpc 0.7); the window label is read from `__TAURI_INTERNALS__.metadata.currentWebview.label`; `plugin:event|listen` is handled for push channels. Fixture payloads (incident / connection / service / report / export / diagnostics) live in `helpers/v02-fixtures.ts`.
- **Static serving:** the SPA is served for audits via `helpers/static-server.mjs` (`http-server` with `-P` SPA fallback) because TanStack Router uses browser history (not hash routing); pa11y-ci server lifecycle runs via `pa11y/run-pa11y.mjs`. Real route paths (incl. `/diagnostics`) are configured in the pa11y + Lighthouse configs. Added devDep: `http-server`.
- **Adding a surface (standing rule):** every new route/modal adds one axe spec in the same chunk (the p8–p14 specs are the template); fixtures go in `helpers/v02-fixtures.ts` OR inline in the spec when they are single-surface; any new TauRPC procedure a fixture consumes is mocked via the `TauRPC__` command shape, and `installTauriIpcMock` additionally honours two response sentinels — `__mockReject` (settle rejected) and `__mockDelayMs` (settle late) — so error and in-flight states are auditable, not only the settled-success one. Fixtures must be POPULATED: an empty array renders nothing, so the sweep audits a blank region and passes by comparing nothing. Verify suite health cheaply with `npx playwright test --config=playwright-a11y.config.ts --list` (a list-time import failure once silently disabled the whole suite). Name the config: the BARE `npx playwright test --list` reads the deliberately inert default `playwright.config.ts` and prints `Total: 0 tests in 0 files`, exit 1, whatever the suite's state (measured at chunk 2026-09-30-perf-instruments-measure-their-budgets: bare → exit 1, 0 tests; config-named → exit 0, 41 tests in 18 files).
- **Regression baseline:** the per-PR regression gate compares against `baselines/a11y-violations-summary.json` — a clean full-chain pass = 0 violation tuples (informational Lighthouse-score tuples allowed).
