## 2026-05-02 — Initial layout templates generated by `/andromeda-design` Phase 8
**Section:** whole document (foundational). Surfaces covered: desktop-webview (compact widget + full dashboard) and desktop-native (tray icon + menu).
**Change:** one-shot generation establishing the body's per-surface layout truth:
- Compact widget — fixed quarter-screen glance surface: frameless titlebar, snap-to-edge, always-on-top, Halo canvas hero, read-only footer; Esc → tray; settings toggle expands to the full dashboard; no CSS media-query breakpoints (min-readable on a 13-inch laptop).
- Full dashboard — resizable, custom titlebar, nav "either tabs OR sidebar" (neither prescribed) over Traces / Metrics / Logs / Snapshots / Settings, per-service Halo on the constellation map hero; no hard breakpoints, nav may collapse tabs → hamburger at narrow widths.
- Tray — monochrome SVG glyph + unified Halo layer (WebGPU canvas or SVG-filter fallback) + flat right-click action menu, OS-native per platform conventions.
- Cross-surface IA — glance / exploration / ambient status; consistent Halo shader logic; shared Tauri 2 broadcast data feeds; same frameless titlebar on both webview surfaces.
- Signature — unified Halo on the compact-widget aggregated service-count badge (bottom-right of the canvas); per-service Halo dots on the constellation map; unified Halo around the tray glyph; data-driven (throughput → pulse frequency, error rate → LCH hue), not decorative.
- Motion — Investigation Capture Collapse on "Investigate"; continuous Halo "breathing" on all three surfaces (exempt from the chrome budget, separate WebGPU canvas layer); Settings-modal open/close over `duration-standard` within the `0.35` webview budget; instant OS-native tray-menu emergence per the `0.2` desktop-native expression level.
- Scope — desktop only (Windows / macOS / Linux); no mobile or touch surface.
- Deferred — snapshot-markdown viewer layout (modal vs. full-page) to the implementation route (snapshots via TauRPC `snapshot.generate`); deep-link / URL-hash structure, while committing to routable views (`/traces`, `/metrics`, `/logs`, `/snapshots`, `/settings`) + keyboard shortcuts.
**Why:** initial generation by `/andromeda-design` Phase 8. Build-ownership boundaries it set: custom titlebar drag region + window-control buttons → route specialist (design gives layout + token references; implementation owns the Tauri 2 IPC minimize / maximize / close); Halo State Pulse WebGPU canvas + WGSL shader → route + obs specialist (canvas init, shaders, data-feed subscription, reduced-motion degradation); TauRPC commands (`snapshot.generate`, `health` polling for the tray summary line, Settings submits, Investigate) → wired by the route specialist, logic in `ui-bridge`; DuckDB → TauRPC → React for constellation positions, `traces.query`, `metrics.query`, `logs.query` → `viz` owns the query schema, route specialist owns component integration.
